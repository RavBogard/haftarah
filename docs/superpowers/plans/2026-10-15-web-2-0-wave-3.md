# Haftarah 2.0, Wave 3: words, translations, and everything on this verse — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the web page three study tools that the curated sheet does not try to be: a word panel that says in plain English what each Hebrew word is doing (STEP TAHOT morphology, precomputed at publish, with in-reading occurrences and a whole-Tanakh count), a translation picker (JPS 2023 default; JPS 1985, Koren, Metsudah where Sefaria has them, cached at publish), and "Everything on this verse" (Sefaria's related texts in textual categories, visibly not the sheet).

**Architecture:** Three new publish-time scripts each write one side file next to `sheet.json` in the Blob store: `scripts/words.mjs` → `words.json`, `scripts/translations.mjs` → `translations.json`, `scripts/links.mjs` → `links.json`. Each is a pure core (parsers, alignment, grouping) with an injectable fetch, plus a thin CLI; `publish.mjs` runs all three before any upload, uploads the side files beside the sheet, writes a `side` manifest into the published `sheet.json` so the page never asks for a file that is not there, and gains `--side <slug>` to backfill an already-published week from the store. The page's words are defined once, DOM-free, in `template/lib.js` (`verseWords`), so publish counts words exactly as the page does; a web-check line holds the two equal. STEP's files are cached outside the repo (`~/.haftarah-cache/`); only the trimmed, per-week derived file and a committed frequency table (counts per dictionary word) ever leave that cache. On the page, `site/app/words.js` composes the plain-English sentence from structured fields, `settings.js` gains a Translation row, and `panel.js` gains the related-texts view.

**Tech Stack:** Node 18+, zero npm dependencies, `node --test`, headless Chrome/Edge through `scripts/chrome.mjs`; STEPBible TAHOT, TBESH and TEHMC (CC BY 4.0, raw.githubusercontent.com/STEPBible/STEPBible-Data); OSHB morphhb (CC BY 4.0) as fallback; Sefaria v3 texts API (`version=english|all`) and `/api/related`; Vercel Blob.

**Spec:** `docs/superpowers/specs/2026-10-15-web-2-0-design.md` (sections 4.3, 4.6, 4.7, 5.5, 5.6, 5.7, 7, 8, 9, 11.5 are this wave). Background: `docs/superpowers/research/2026-10-15-web-2-0/words-and-translations.md` (all of it). Format and earlier decisions: `docs/superpowers/plans/2026-10-15-web-2-0-wave-2.md`.

```js
  // The words of a verse as the web page counts them (spec 4.3): every Hebrew word of the reading,
  // not the keyed letters (<sup>), not the ketiv (Sefaria's mam-kq-k span; the page's .ketiv), not a
  // MAM footnote. Tags are stripped, thin and no-break spaces become spaces. DOM-free, so publish
  // can number the words exactly as the page does.
  function verseWords(heHtml) {
    const s = String(heHtml == null ? "" : heHtml)
      .replace(/<sup\b[^>]*>[\s\S]*?<\/sup>/g, "")
      .replace(/<span class="(?:mam-kq-k|ketiv)">[\s\S]*?<\/span>/g, "")
      .replace(/<i class="footnote">[\s\S]*?<\/i>/g, "")
      .replace(/<[^>]+>/g, "")
      .replace(/&thinsp;|&nbsp;| | /g, " ");
    return hebrewWords(s);
  }
```

### Task 2: `scripts/words.mjs`, the pure core: STEP and OSHB parsers, morph decoding, alignment (Opus)

**Files:**
- Create: `scripts/words.mjs`, `tests/words.test.mjs`

**Interfaces:**
- Consumes: `L.verseWords`, `L.stripMarks`, `L.divineName` (via `createRequire`).
- Produces (all exported from `scripts/words.mjs`, pure, no I/O):
  - `BOOKS`: `{ [sefariaBook]: { step, group, osis } }` for the 26 books a sheet can draw on (the five of the Torah and the 21 of the Prophets; `group` is `Gen-Deu` | `Jos-Est` | `Isa-Mal`).
  - `skeleton(s) → string`: consonants only, after `divineName` (so יהוה and יי both give `יי`).
  - `parseTahot(text, stepCode) → Map<"<ch>:<v>", Row[]>` keyed by the Hebrew chapter and verse (the bracketed ref when present), rows in `#NN` order, type `X` rows dropped; `Row = { n, type, he (the word with its `/` morpheme breaks, punctuation after `\` removed), gloss, strongs, morph, ketiv: string|null }`.
  - `parseTbesh(text) → Map<dStrong, { he, gloss, morph }>` keyed by the `dStrong` column with its trailing letter (`H1254A`), the `=` and anything after it dropped.
  - `parseOshb(xml, osisCode) → Map<"<ch>:<v>", Row[]>` in the same `Row` shape (gloss `""`, strongs built from `lemma` as `H` + four digits + an uppercase letter, prefixes `c b l k m d s` mapped to `H9002 H9003 H9005 H9004 H9006 H9009 H9007`; a `type="x-ketiv"` word is replaced by the qere inside its `<rdg type="x-qere">`, with the ketiv kept in `ketiv`).
  - `decodeMorph(code) → Seg[]`: one entry per `/` part, from `Hc/Vqw3ms`-style codes (leading `H`/`A` dropped). `Seg = { k, ...fields }` where `k` ∈ `c` (vav consecutive, lowercase c in TAHOT), `C` conjunction, `R` preposition (`def: true` for `Rd`), `T` particle with `kind` ∈ `a c d e i j m n o r`, `D` adverb, `V` verb with `stem` (the OSHB stem letter), `form` (`p q i w h j v r s a c`), `p`, `g`, `n`; `N` noun with `kind` (`c` common, `p` proper, `g` gentilic), `g`, `n`, `st` (`a c d`), and for a TAHOT proper noun `pk` (`m f l t`: person m/f, location, title); `A` adjective with `kind` (`a c g o`), `g`, `n`, `st`; `P` pronoun with `kind` (`d f i p r`), `p`, `g`, `n`; `S` suffix with `kind` (`d h n p`), `p`, `g`, `n`. Unknown letters are kept in `raw` and never throw.
  - `segmentsOf(row) → Seg[]`: `decodeMorph(row.morph)` zipped with the row's Hebrew parts (`t`), glosses (`gl`, trimmed, `<…>` and `[…]` kept as given) and dStrongs (`lem`, braces removed; the root part is the one that had braces); the row's root dStrong is `rootOf(row)`.
  - `alignVerse(pageWords: string[], rows: Row[]) → { pairs: [i, j][], missing: number[] }` by longest common subsequence over skeletons.
  - `STEMS`, `STEM_HINTS`, `FORMS`, `PARTICLES`, `GENDER`, `NUMBER`, `PERSON`: the label tables the page reuses (Task 7 imports the same tables from this module? No: `site/app/` cannot import from `scripts/`; Task 7 copies the tables into `site/app/words.js` and a test holds the two copies equal).

```js
// A word row: "<Book>.<ch>.<v>[(<heCh>.<heV>)]#<nn>=<type>\t<hebrew>\t<translit>\t<gloss>\t<dStrongs>\t<morph>\t<meaning variants>\t..."
// The ref is the English numbering with the Hebrew in brackets when it differs; rows are keyed here by
// the Hebrew. Punctuation follows a backslash in the Hebrew and the dStrongs. Type X rows are words
// from the Septuagint that are not in the Masoretic text.
const TAHOT_ROW = /^([A-Za-z0-9]+)\.(\d+)\.(\d+)(?:\((\d+)\.(\d+)\))?#(\d+)=(\S*)\t([^\t\n]*)\t[^\t\n]*\t([^\t\n]*)\t([^\t\n]*)\t([^\t\n]*)\t([^\t\n]*)/gm;
// groups: 1 book, 2 ch, 3 v, 4 heCh, 5 heV, 6 n, 7 type, 8 hebrew, (transliteration skipped), 9 gloss, 10 dStrongs, 11 morph, 12 meaning variants
const KETIV_IN_VARIANT = /K=\s*\S+\s*\(([^)]*)\)/;

export function parseTahot(text, stepCode) {
  const out = new Map();
  TAHOT_ROW.lastIndex = 0;
  let m;
  while ((m = TAHOT_ROW.exec(text))) {
    if (m[1] !== stepCode || m[7].startsWith("X")) continue;
    const ch = m[4] ? +m[4] : +m[2], v = m[5] ? +m[5] : +m[3];
    const key = `${ch}:${v}`;
    if (!out.has(key)) out.set(key, []);
    const kv = m[7].startsWith("Q") ? KETIV_IN_VARIANT.exec(m[12]) : null;
    out.get(key).push({ n: +m[6], type: m[7], he: m[8].split("\\")[0], gloss: m[9], strongs: m[10].split("\\")[0], morph: m[11], ketiv: kv ? kv[1] : null });
  }
  for (const rows of out.values()) rows.sort((a, b) => a.n - b.n);
  return out;
}
```

```js
export function parseTbesh(text) {
  const out = new Map();
  for (const line of String(text).split(/\r?\n/)) {
    const f = line.split("\t");
    if (f.length < 7 || !/^H\d{4}/.test(f[0])) continue;
    const d = (f[1] || "").trim().split(/\s+/)[0];
    if (!/^H\d{4}[A-Za-z]?$/.test(d)) continue;
    out.set(d, { he: f[3].trim(), gloss: f[6].trim(), morph: f[5].trim() });
  }
  return out;
}

// ---- OSHB morphhb (wlc/<osis>.xml): the fallback source, in the same row shape ----
const OSHB_PREFIX = { c: "H9002", b: "H9003", k: "H9004", l: "H9005", m: "H9006", s: "H9007", d: "H9009" };
const oshbStrong = part => {
  const m = /^(\d+)\s*([a-z])?$/.exec(part.trim());
  if (m) return `H${m[1].padStart(4, "0")}${m[2] ? m[2].toUpperCase() : ""}`;
  return OSHB_PREFIX[part.trim()] || part.trim();
};

// OSHB tags a prefix in the lemma ("c/7121") but not a pronominal suffix ("אֲדֹנָֽי/ו" has lemma "113" and
// morph "HNcmpc/Sp3ms"): the suffix's STEP number comes from the morph. A ketiv word is replaced by
// the qere in its note; the ketiv is kept on the row.
// OSHB pronominal-suffix tags → STEP's suffix numbers (possessive Ps on nouns, object Os on verbs and prepositions).
const SUFFIX_STRONG = {
  "1cs": ["H9020", "H9030"], "2ms": ["H9021", "H9031"], "2fs": ["H9022", "H9032"], "3ms": ["H9023", "H9033"], "3fs": ["H9024", "H9034"],
  "1cp": ["H9025", "H9035"], "2mp": ["H9026", "H9036"], "2fp": ["H9027", "H9037"], "3mp": ["H9028", "H9038"], "3fp": ["H9029", "H9039"],
  "1bs": ["H9020", "H9030"], "1bp": ["H9025", "H9035"], "3cp": ["H9028", "H9038"],
};

export function parseOshb(xml, osisCode) {
  const out = new Map();
  const verseRe = /<verse osisID="([A-Za-z0-9]+)\.(\d+)\.(\d+)">([\s\S]*?)<\/verse>/g;
  let v;
  while ((v = verseRe.exec(xml))) {
    if (v[1] !== osisCode) continue;
    const body = v[4].replace(/<w type="x-ketiv"[^>]*>([^<]*)<\/w><note type="variant">[\s\S]*?<rdg type="x-qere">(<w [^>]*>[^<]*<\/w>)<\/rdg><\/note>/g, (_, k, qw) => qw.replace(/^<w /, `<w data-ketiv="${k}" `));
    const rows = [];
    const wRe = /<w ([^>]*)>([^<]*)<\/w>/g;
    let w;
    while ((w = wRe.exec(body))) {
      const attr = name => { const m = new RegExp(`${name}="([^"]*)"`).exec(w[1]); return m ? m[1] : ""; };
      const morph = attr("morph"), morphParts = morph.replace(/^[HA]/, "").split("/");
      const lemma = attr("lemma").split("/").map(oshbStrong);
      const parts = [];
      let li = 0;
      for (const mp of morphParts) {
        if (/^S[dhnp]/.test(mp) && li >= lemma.length) {   // a suffix OSHB does not tag: its number from the morph
          const pgn = mp.slice(2), pair = SUFFIX_STRONG[pgn] || [];
          parts.push(/^S[dhn]/.test(mp) ? "H9011" : (morphParts[0].startsWith("N") || morphParts[0].startsWith("A") ? pair[0] : pair[1]) || "H9050");
        } else parts.push(lemma[li++] || "");
      }
      const found = parts.findIndex(p => p && !/^H90\d\d$/.test(p));
      const rootAt = found < 0 ? parts.length - 1 : found;   // ל/וֹ is all prefix and suffix: the suffix is the root, as in TAHOT
      const strongs = parts.map((p, i) => (i === rootAt ? `{${p}}` : p)).filter(Boolean).join("/");
      rows.push({ n: rows.length + 1, type: "L", he: w[2], gloss: "", strongs, morph, ketiv: attr("data-ketiv") || null });
    }
    if (rows.length) out.set(`${v[2]}:${v[3]}`, rows);
  }
  return out;
}
```

```js
// A code is one part per morpheme, split by "/": Hc/Vqw3ms = vav consecutive + verb Qal wayyiqtol 3ms.
export const STEMS = { q: "Qal", N: "Niphal", p: "Piel", P: "Pual", h: "Hiphil", H: "Hophal", t: "Hithpael", o: "Polel", O: "Polal", r: "Hithpolel", m: "Poel", M: "Poal", k: "Palel", K: "Pulal", Q: "Qal passive", l: "Pilpel", L: "Polpal", f: "Hithpalpel", D: "Nithpael", j: "Pealal", i: "Pilel", u: "Hothpaal", c: "Tiphil", v: "Hishtaphel", w: "Nithpalel", y: "Nithpoel", z: "Hithpoel" };

  r: ["active participle", "-ing; one who"], s: ["passive participle", "-ed; being"],
  a: ["infinitive absolute", "the bare verb, for emphasis"], c: ["infinitive construct", "to …"],
};

export const PERSON = { 1: "1st person", 2: "2nd person", 3: "3rd person" };
export const GENDER = { m: "masculine", f: "feminine", c: "common", b: "either gender" };
export const NUMBER = { s: "singular", p: "plural", d: "dual" };

function pgn(s, seg) { if (/^[123]/.test(s)) { seg.p = +s[0]; s = s.slice(1); } if (s[0] && GENDER[s[0]]) { seg.g = s[0]; s = s.slice(1); } if (s[0] && NUMBER[s[0]]) { seg.n = s[0]; s = s.slice(1); } return s; }
function gns(s, seg) { if (s[0] && GENDER[s[0]]) { seg.g = s[0]; s = s.slice(1); } if (s[0] && NUMBER[s[0]]) { seg.n = s[0]; s = s.slice(1); } if (s[0] && STATE[s[0]]) { seg.st = s[0]; s = s.slice(1); } return s; }

export function decodeMorph(code) {
  const s = String(code == null ? "" : code).replace(/^[HA]/, "");
  if (!s) return [];
  return s.split("/").map(part => {
    const k = part[0], rest = part.slice(1);
    switch (k) {
      case "c": return { k: "c" };
      case "C": return { k: "C" };
      case "D": return { k: "D" };
      case "R": return rest === "d" ? { k: "R", def: true } : { k: "R" };
      case "T": return { k: "T", kind: rest[0] || "" };
      case "V": { const seg = { k: "V", stem: rest[0], form: rest[1] }; const tail = rest.slice(2); if (seg.form === "r" || seg.form === "s") gns(tail, seg); else pgn(tail, seg); return seg; }
      case "N": { const seg = { k: "N", kind: rest[0] }; const tail = rest.slice(1); if (seg.kind === "p") { if (tail[0]) seg.pk = tail[0]; } else gns(tail, seg); return seg; }
      case "A": { const seg = { k: "A", kind: rest[0] }; gns(rest.slice(1), seg); return seg; }
      case "P": { const seg = { k: "P", kind: rest[0] }; pgn(rest.slice(1), seg); return seg; }
      case "S": { const seg = { k: "S", kind: rest[0] }; if (seg.kind === "p") pgn(rest.slice(1), seg); return seg; }
      default: return { k: k || "?", raw: part };
    }
  });
}

/** A row's root dStrong (the braced one), or null. */
export const rootOf = row => { const m = /\{(H\d{4}[A-Za-z]?)\}/.exec(String(row && row.strongs || "")); return m ? m[1] : null; };

/** The row's morphemes: the decoded code zipped with its Hebrew pieces, glosses and dStrongs. */
export function segmentsOf(row) {
  const he = String(row.he || "").split("/"), gl = String(row.gloss || "").split("/").map(s => s.trim());
  const lem = String(row.strongs || "").split("/"), morph = decodeMorph(row.morph);
  return he.map((t, i) => {
    const seg = { ...(morph[i] || {}), t };
    if (!morph[i]) return { t };
    if (gl[i] != null && gl[i] !== "") seg.gl = gl[i];
    if (lem[i]) { seg.lem = lem[i].replace(/[{}]/g, ""); if (/^\{/.test(lem[i])) seg.root = true; }
    return seg;
  });
}

// ---- alignment: the page's words against the source's rows, by consonant skeleton ----
function lcs(a, b) {
  const n = a.length, m = b.length, dp = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(0));
  for (let i = n - 1; i >= 0; i--) for (let j = m - 1; j >= 0; j--) dp[i][j] = a[i] === b[j] ? dp[i + 1][j + 1] + 1 : Math.max(dp[i + 1][j], dp[i][j + 1]);
  const pairs = [];
  let i = 0, j = 0;
  while (i < n && j < m) { if (a[i] === b[j]) { pairs.push([i, j]); i++; j++; } else if (dp[i + 1][j] >= dp[i][j + 1]) i++; else j++; }
  return pairs;
}

/** pairs[i] = [page word index, row index]; missing = page words with no row. Nothing is guessed. */
export function alignVerse(pageWords, rows) {
  const pa = pageWords.map(skeleton), ra = rows.map(r => skeleton(String(r.he || "").replace(/\//g, "")));
  const pairs = lcs(pa, ra);
  const hit = new Set(pairs.map(p => p[0]));
  return { pairs, missing: pageWords.map((_, i) => i).filter(i => !hit.has(i)) };
}
```

```js
/** The cache paths of `files` (relative names), downloading each one the cache lacks; whole files only. */
export async function ensureFiles(files, { dir, fetchImpl = globalThis.fetch, log = console.log } = {}) {
  const out = [];
  for (const file of files) {
    const path = join(dir, file);
    if (!(await exists(path))) {
      const url = urlOf(file);
      if (!url) throw new Error(`${file}: no known source`);
      log(`downloading ${file} from ${url.replace(/%20/g, " ")}`);
      let res;
      try { res = await fetchImpl(url); } catch (err) { throw new Error(`${file}: network error: ${err.cause?.code || err.message}`); }
      if (!res.ok) throw new Error(`${file}: HTTP ${res.status} from ${url}`);
      await mkdir(dirname(path), { recursive: true });
      const tmp = `${path}.part`;
      await writeFile(tmp, Buffer.from(await res.arrayBuffer()));
      await rename(tmp, path);
    }
    out.push(path);
  }
  return out;
}

// ---- the frequency table: how often each dictionary word is tagged in the whole Hebrew Bible ----
const FREQ_ROW = /^[A-Za-z0-9]+\.\d+\.\d+(?:\(\d+\.\d+\))?#\d+=(\S*)\t[^\t\n]*\t[^\t\n]*\t[^\t\n]*\t([^\t\n]*)\t/gm;
export function frequencyTable(texts) {
  const freq = {};
  for (const text of texts) {
    FREQ_ROW.lastIndex = 0;
    let m;
    while ((m = FREQ_ROW.exec(text))) {
      if (m[1].startsWith("X")) continue;
      const lem = (/\{(H\d{4}[A-Za-z]?)\}/.exec(m[2]) || [])[1];
      if (lem) freq[lem] = (freq[lem] || 0) + 1;
    }
  }
  return freq;
}
async function loadFrequency() { try { return JSON.parse(await readFile(FREQUENCY_FILE, "utf8")); } catch { return {}; } }

// ---- words.json for one sheet ----
/**
 * sheet → { words, report }. `rows` holds, per reading id, the source's rows keyed "<ch>:<v>"; `lexicon`
 * is TBESH (a Map; empty for OSHB); `frequency` the table. A verse with words and no rows is an error
 * (nothing is guessed); a word that does not align is left out of its verse and named.
 */
export function wordsFor(sheet, { source = "tahot", rows, lexicon = new Map(), frequency = {} }) {
  const words = { schema: 1, slug: sheet.slug || "", source, credit: CREDITS[source], readings: {}, lemmas: {} };
  const report = { readings: {} };
  const lemma = d => { if (!(d in words.lemmas)) { const x = lexicon.get(d) || { he: "", gloss: "" }; words.lemmas[d] = { he: x.he, gloss: x.gloss, ...(frequency[d] ? { all: frequency[d] } : {}) }; } };
  for (const r of L.readings(sheet)) {
    if (!(r.verses || []).length) continue;
    const model = L.readingModel(sheet, r.id);
    const src = rows[r.id] || new Map();
    const out = { book: r.book || "", verses: {}, missing: [] };
    const rep = { words: 0, aligned: 0, missing: [] };
    for (const v of model.verses) {
      const page = L.verseWords(v.heHtml).map(w => w.text);
      if (!page.length) continue;
      const key = `${v.chapter}:${v.verse}`;
      const vr = src.get(key);
      if (!vr || !vr.length) throw new Error(`words: ${r.book} ${key} has no rows in ${source}; STEP numbers verses by the English Bible, check the bracketed Hebrew refs`);
      const { pairs, missing } = alignVerse(page, vr);
      rep.words += page.length; rep.aligned += pairs.length;
      for (const i of missing) { out.missing.push(`${key}/${i}`); rep.missing.push(`${key}/${i} ${page[i]}`); }
      out.verses[key] = pairs.map(([i, j]) => {
        const row = vr[j], lem = rootOf(row);
        const seg = segmentsOf(row);
        for (const s of seg) if (s.lem) lemma(s.lem);
        return { i, seg, lem, morph: row.morph || "", ketiv: row.ketiv || null };
      });
    }
    words.readings[r.id] = out;
    report.readings[r.id] = rep;
  }
  return { words, report };
}

/** Read dir/sheet.json, load the sources from the cache, write dir/words.json, log one line per reading. */
export async function buildWords(dir, { source = "tahot", cache = cacheDir(), fetchImpl = globalThis.fetch, log = console.log, frequency = null } = {}) {
  const sheet = JSON.parse(await readFile(join(dir, "sheet.json"), "utf8"));
  const rows = {}, texts = new Map();
  const text = async file => { if (!texts.has(file)) texts.set(file, readFile((await ensureFiles([file], { dir: cache, fetchImpl, log }))[0], "utf8")); return texts.get(file); };
  for (const r of L.readings(sheet)) {
    if (!(r.verses || []).length) continue;
    const book = BOOKS[r.book];
    if (!book) throw new Error(`words: no word data for the book "${r.book}"`);
    rows[r.id] = source === "oshb" ? parseOshb(await text(oshbFile(book.osis).file), book.osis) : parseTahot(await text(STEP_FILES[book.group].file), book.step);
  }
  const lexicon = source === "oshb" ? new Map() : parseTbesh(await text(STEP_FILES.TBESH.file));
  const { words, report } = wordsFor(sheet, { source, rows, lexicon, frequency: frequency || (await loadFrequency()) });
  const file = join(dir, "words.json");
  await writeFile(file, JSON.stringify(words));
  for (const [id, rep] of Object.entries(report.readings)) {
    log(`words    ${id}  ${rep.words} words, ${rep.aligned} with analysis, ${rep.missing.length} missing${rep.missing.length ? `: ${rep.missing.join(", ")}` : ""}`);
  }
  return { file, report };
}

/** Alignment coverage for a live reference (the MAM Hebrew from Sefaria, GET only), for the wave's checks. */
export async function checkRef(ref, { cache = cacheDir(), fetchImpl = globalThis.fetch, log = console.log } = {}) {
  const res = await fetchImpl(`https://www.sefaria.org/api/v3/texts/${encodeURIComponent(ref.replace(/\s+/g, " "))}?version=hebrew|${encodeURIComponent("Miqra according to the Masorah")}&return_format=default`);
  if (!res.ok) throw new Error(`Sefaria answered HTTP ${res.status} for ${ref}`);
  const tx = await res.json();
  const he = (tx.versions || [])[0];
  if (!he) throw new Error(`Sefaria has no Hebrew for ${ref}`);
  const book = tx.book || ref.replace(/\s+\d.*$/, ""), info = BOOKS[book];
  if (!info) throw new Error(`no word data for the book "${book}"`);
  const startCh = +tx.sections[0], startV = +(tx.sections[1] ?? 1), verses = [];
  if (he.text.length && Array.isArray(he.text[0])) he.text.forEach((ch, ci) => ch.forEach((t, vi) => verses.push({ chapter: startCh + ci, verse: (ci === 0 ? startV : 1) + vi, he: t })));
  else he.text.forEach((t, vi) => verses.push({ chapter: startCh, verse: startV + vi, he: t }));
  const rows = parseTahot(await readFile((await ensureFiles([STEP_FILES[info.group].file], { dir: cache, fetchImpl, log }))[0], "utf8"), info.step);
  let words = 0, aligned = 0; const missing = [];
  for (const v of verses) {
    const page = L.verseWords(String(v.he).replace(/<span class="mam-spi-[^"]*">\{[ספ]\}<\/span>/g, " ")).map(w => w.text);
    const a = alignVerse(page, rows.get(`${v.chapter}:${v.verse}`) || []);
    words += page.length; aligned += a.pairs.length;
    for (const i of a.missing) missing.push(`${v.chapter}:${v.verse}/${i} ${page[i]}`);
  }
  log(`${ref}: ${words} words, ${aligned} with analysis (${(100 * aligned / Math.max(1, words)).toFixed(1)}%)${missing.length ? `; missing: ${missing.join(", ")}` : ""}`);
  return { words, aligned, missing };
}
```

```js
/**
 * translations.mjs — the other English versions a reader can switch to (spec 5.6), fetched from
 * Sefaria at publish into weeks/<slug>/translations.json. The sheet's own English (JPS 2023) is the
 * default and lives in sheet.json; this file holds the rest, verse-aligned, with each version's title
 * and licence so the page can credit what it shows. Only the editions in customs.translations that

import { readFile, writeFile } from "node:fs/promises";
import { join, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { createRequire } from "node:module";
import { getJSON, flattenVerses } from "./fetch.mjs";
import { loadCustoms } from "./customs.mjs";

const L = createRequire(import.meta.url)("../template/lib.js");

export const DEFAULT_KEY = "jps2023";
export const DEFAULT_LABEL = "JPS 2023";
// Keys are what customs.translations names; titles are Sefaria's exact versionTitle strings.
export const TRANSLATIONS = {
  jps1985: { label: "JPS 1985", titles: ["Tanakh: The Holy Scriptures, published by JPS"], credit: "English: Tanakh: The Holy Scriptures (The Jewish Publication Society, 1985), CC BY-NC, via Sefaria." },
  koren: { label: "Koren", titles: ["The Koren Jerusalem Bible"], credit: "English: The Koren Jerusalem Bible (Koren Publishers Jerusalem), CC BY-NC, via Sefaria." },
  metsudah: {
    label: "Metsudah",
    titles: ["The Metsudah Tanach series, Lakewood, N.J", "Metsudah Chumash, Metsudah Publications, 2009"],
    credits: {
      "The Metsudah Tanach series, Lakewood, N.J": "English: The Metsudah Tanach series (Lakewood, N.J.), CC BY, via Sefaria.",
      "Metsudah Chumash, Metsudah Publications, 2009": "English: Metsudah Chumash (Metsudah Publications, 2009), CC BY, via Sefaria.",
    },
  },
};
const creditFor = (key, title) => TRANSLATIONS[key].credits ? TRANSLATIONS[key].credits[title] : TRANSLATIONS[key].credit;

/** A verse's HTML without Sefaria's footnotes (they belong to that edition, not to the sheet's keyed notes). */
export function plainVersion(html) {
  return String(html == null ? "" : html)
    .replace(/<sup class="footnote-marker">[^<]*<\/sup>/g, "")
    .replace(/<i class="footnote">(?:<i>.*?<\/i>|(?!<\/i>)[\s\S])*?<\/i>/g, "")
    .replace(/\s+(<br\s*\/?>)/g, "$1").replace(/[ \t]{2,}/g, " ").trim();
}

export const versionsOf = json => ((json && json.versions) || []).filter(v => v && v.language === "en").map(v => ({ versionTitle: v.versionTitle || "", license: v.license || "", text: v.text }));

const textsUrl = ref => `https://www.sefaria.org/api/v3/texts/${encodeURIComponent(ref.replace(/\s+/g, " "))}?version=${encodeURIComponent("english|all")}&return_format=default`;

export async function translationsFor(sheet, customs, { get = getJSON } = {}) {
  const wanted = (customs.translations || []).filter(k => k !== DEFAULT_KEY);
  const unknown = wanted.filter(k => !TRANSLATIONS[k]);
  const keys = wanted.filter(k => TRANSLATIONS[k]);
  const translations = { schema: 1, slug: sheet.slug || "", readings: {} };
  const report = {};
  for (const r of L.readings(sheet)) {
    if (!(r.verses || []).length) continue;
    let json;
    try { json = await get(textsUrl(r.ref)); } catch (err) { throw new Error(`translations: ${r.id} (${r.ref}): ${err.message}`); }
    const have = versionsOf(json);
    const versions = [], offered = [], absent = [];
    for (const key of keys) {
      const title = TRANSLATIONS[key].titles.find(t => have.some(v => v.versionTitle === t));
      if (!title) { absent.push(key); continue; }
      const v = have.find(x => x.versionTitle === title);
      const flat = flattenVerses(v.text || [], json.sections || [], json.toSections || []);
      const byKey = new Map(flat.map(x => [`${x.chapter}:${x.verse}`, plainVersion(x.text)]));
      const verses = {};
      for (const sv of r.verses) verses[`${sv.chapter}:${sv.verse}`] = byKey.get(`${sv.chapter}:${sv.verse}`) || "";
      versions.push({ key, label: TRANSLATIONS[key].label, title, license: v.license, credit: creditFor(key, title), verses });
      offered.push(key);
    }
    translations.readings[r.id] = { ref: r.ref, versions };
    report[r.id] = { offered, absent, ...(unknown.length ? { unknown } : {}) };
  }
  return { translations, report };
}

export async function buildTranslations(dir, { customs, get = getJSON, log = console.log } = {}) {
  const sheet = JSON.parse(await readFile(join(dir, "sheet.json"), "utf8"));
  const { translations, report } = await translationsFor(sheet, customs, { get });
  const file = join(dir, "translations.json");
  await writeFile(file, JSON.stringify(translations));
  for (const [id, rep] of Object.entries(report)) {
    log(`translations  ${id}  ${rep.offered.join(", ") || "none"}${rep.absent.length ? ` (not on Sefaria for this book: ${rep.absent.join(", ")})` : ""}${rep.unknown ? ` (unknown in customs: ${rep.unknown.join(", ")})` : ""}`);
  }
  return { file, report };
}

if (process.argv[1] && fileURLToPath(import.meta.url) === resolve(process.argv[1])) {
  const args = process.argv.slice(2);
  const i = args.indexOf("--customs");
  const dir = args.find((a, j) => !a.startsWith("--") && j !== i + 1);
  if (!dir) { console.error("usage: node scripts/translations.mjs weeks/<slug> [--customs crc]"); process.exit(1); }
  loadCustoms(i >= 0 ? args[i + 1] : "crc").then(customs => buildTranslations(dir, { customs })).catch(err => { console.error(`translations: ${err.message}`); process.exit(1); });
}
```

```js
#!/usr/bin/env node
/**
 * links.mjs — "Everything on this verse" (spec 5.7): what Sefaria links to each verse, in textual
 * categories only, grouped by work, with no text (the page fetches one item when it is tapped).
 * Written at publish into weeks/<slug>/links.json. User sheets, topics, manuscripts, media and essays
 * are never kept. Visibly not the sheet: the page says so.
 *
 *   node scripts/links.mjs weeks/<slug>
 */
import { readFile, writeFile } from "node:fs/promises";
import { join, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { createRequire } from "node:module";
import { getJSON } from "./fetch.mjs";

const L = createRequire(import.meta.url)("../template/lib.js");

export const CATEGORIES = ["Commentary", "Targum", "Midrash", "Talmud", "Halakhah", "Kabbalah", "Chasidut", "Jewish Thought", "Musar", "Second Temple", "Reference", "Liturgy", "Tanakh", "Quoting Commentary"];
const BY_WORK = new Set(["Commentary", "Quoting Commentary"]);

/** Sefaria's links for one verse → the spec's categories in order, each by work, Hebrew-only refs apart. */
export function groupLinks(links) {
  const byCat = new Map();
  let n = 0;
  for (const l of Array.isArray(links) ? links : []) {
    if (!l || !CATEGORIES.includes(l.category) || !l.ref) continue;
    const title = (BY_WORK.has(l.category) && l.collectiveTitle && l.collectiveTitle.en) || l.index_title || l.ref;
    if (!byCat.has(l.category)) byCat.set(l.category, new Map());
    const works = byCat.get(l.category);
    if (!works.has(title)) works.set(title, { title, refs: [], he: [], num: l.commentaryNum != null ? Number(l.commentaryNum) : null });
    const w = works.get(title);
    (l.sourceHasEn === false ? w.he : w.refs).push(l.ref);
    n++;
  }
  const groups = CATEGORIES.filter(c => byCat.has(c)).map(category => ({
    category,
    works: [...byCat.get(category).values()]
      .sort((a, b) => (a.num != null && b.num != null ? a.num - b.num : a.num != null ? -1 : b.num != null ? 1 : a.title.localeCompare(b.title)))
      .map(({ title, refs, he }) => ({ title, refs, he })),
  }));
  return { n, groups };
}

const relatedUrl = ref => `https://www.sefaria.org/api/related/${encodeURIComponent(ref.replace(/\s+/g, " "))}`;

export async function relatedFor(sheet, { get = getJSON } = {}) {
  const links = { schema: 1, slug: sheet.slug || "", readings: {} };
  const report = {};
  for (const r of L.readings(sheet)) {
    if (!(r.verses || []).length) continue;
    const verses = {};
    const rep = { verses: 0, links: 0, failed: [] };
    for (const v of r.verses) {
      const key = `${v.chapter}:${v.verse}`;
      rep.verses++;
      try {
        const json = await get(relatedUrl(`${v.book || r.book} ${key}`));
        verses[key] = groupLinks(json && json.links);
        rep.links += verses[key].n;
      } catch {
        verses[key] = { n: 0, groups: [], failed: true };
        rep.failed.push(key);
      }
    }
    links.readings[r.id] = { verses };
    report[r.id] = rep;
  }
  return { links, report };
}

export async function buildLinks(dir, { get = getJSON, log = console.log } = {}) {
  const sheet = JSON.parse(await readFile(join(dir, "sheet.json"), "utf8"));

  return { file, report };
}
```

```js
const pgn = seg => [seg.p && PERSON[seg.p], seg.g && seg.g !== "b" && GENDER[seg.g], seg.n && NUMBER[seg.n]].filter(Boolean).join(" ");

function chip(seg, lemmas) {
  const gl = cleanGloss(seg.gl);
  if (gl) return { t: seg.t, text: gl };
  if (seg.k === "S" && seg.kind === "p") return { t: seg.t, text: SUFFIX_GLOSS[`${seg.p || ""}${seg.g === "b" || seg.g === "c" ? "" : seg.g || ""}${seg.n || ""}`] || (lemmas[seg.lem] && lemmas[seg.lem].gloss) || "suffix" };
  if (seg.k === "S") return { t: seg.t, text: seg.kind === "d" ? "to, toward (directional)" : "ending" };
  return { t: seg.t, text: PREFIX_GLOSS[seg.lem] || (lemmas[seg.lem] && lemmas[seg.lem].gloss) || (seg.k === "T" && seg.kind === "d" ? "the" : seg.k === "R" ? "preposition" : "and") };
}

/** The sentence, the detail line, the prefix and suffix chips, and the dictionary word for one words.json entry. */
export function describe(word, lemmas = {}) {
  if (!word || !Array.isArray(word.seg) || !word.seg.length) return { sentence: "No word analysis for this word.", detail: "", before: [], after: [], root: null, code: "" };
  const segs = word.seg;
  let ri = segs.findIndex(s => s.root);
  if (ri < 0) ri = Math.max(0, segs.findIndex(s => s.lem && !/^H90\d\d$/.test(s.lem)));
  const r = segs[ri];
  const before = segs.slice(0, ri).map(s => chip(s, lemmas)), after = segs.slice(ri + 1).map(s => chip(s, lemmas));
  const lem = word.lem || r.lem || "";
  const lx = lemmas[lem] || {};
  const root = { lem, he: lx.he || "", gloss: lx.gloss || "", all: lx.all };
  const gl = cleanGloss(r.gl);
  const said = gl ? `: ${q(gl)}` : "";
  let sentence, detail;
  if (isDivine(lem)) { sentence = "The divine name, יי."; detail = "proper noun"; root.he = "יי"; root.gloss = "the Name"; }
  else switch (r.k) {
    case "V": {
      const lay = FORM_LAY[r.form] || "a verb form", stem = STEMS[r.stem], hint = STEM_HINTS[r.stem];
      sentence = `A verb, ${lay}${said}.${stem ? ` ${cap(hint || stem)}${hint ? ` (${stem})` : ""}.` : ""}`;
      detail = [stem, FORMS[r.form] && FORMS[r.form][0], r.form === "r" || r.form === "s" ? [gn(r), r.st && STATE[r.st]].filter(Boolean).join(" ") : pgn(r)].filter(Boolean).join(" · ");
      break;
    }
    case "N":
      if (r.kind === "p") { sentence = `${r.pk === "l" ? "A place name" : r.pk === "t" ? "A title or name" : "A name"}${said}.`; detail = "proper noun"; }
      else if (r.kind === "g") { sentence = `A people's name${said}.`; detail = "gentilic noun"; }
      else { sentence = `A noun, ${gn(r)}${r.st === "c" ? ", in construct (‘… of’)" : r.st === "d" ? ", definite" : ""}${said}.`; detail = ["noun", [gn(r), r.st && STATE[r.st]].filter(Boolean).join(" ")].filter(Boolean).join(" · "); }
      break;
    case "A":
      sentence = r.kind === "c" ? `A number${said}.` : r.kind === "o" ? `An ordinal number${said}.` : r.kind === "g" ? `A people's name, as an adjective${said}.` : `An adjective, ${gn(r)}${said}.`;
      detail = ["adjective", [gn(r), r.st && STATE[r.st]].filter(Boolean).join(" ")].filter(Boolean).join(" · ");
      break;
    case "P":
      sentence = r.kind === "p" ? `A pronoun, ${pgn(r)}${said}.` : r.kind === "d" ? `A demonstrative (this, that)${said}.` : r.kind === "i" ? `A question word${said}.` : r.kind === "r" ? `A relative pronoun (which, that)${said}.` : `A pronoun${said}.`;
      detail = ["pronoun", pgn(r)].filter(Boolean).join(" · ");
      break;
    case "T": sentence = `A particle, ${PARTICLES[r.kind] || "particle"}${said}.`; detail = "particle"; break;
    case "R": sentence = `A preposition${said}.`; detail = "preposition"; break;
    case "C": case "c": sentence = `A conjunction${said}.`; detail = "conjunction"; break;
    case "D": sentence = `An adverb${said}.`; detail = "adverb"; break;
    case "S": sentence = `A pronoun suffix${r.kind === "p" ? `, ${pgn(r)}` : ""}${said}.`; detail = "suffix"; break;
    default: sentence = gl ? `${q(gl)}.` : "A word."; detail = "";
  }
  return { sentence, detail, before, after, root, code: word.morph || "" };
}

/** Every word of the reading with this dictionary word, in verse order: { key: "20:18", i, gloss }. */
export function occurrences(words, readingId, lem) {
  const verses = (words && words.readings && words.readings[readingId] && words.readings[readingId].verses) || {};
  const out = [];
  for (const [key, list] of Object.entries(verses)) for (const w of list) if (w.lem === lem) { const r = (w.seg || []).find(s => s.root) || (w.seg || [])[0] || {}; out.push({ key, i: w.i, gloss: cleanGloss(r.gl) }); }
  return out.sort((a, b) => { const [ac, av] = a.key.split(":").map(Number), [bc, bv] = b.key.split(":").map(Number); return ac - bc || av - bv || a.i - b.i; });
}
export const hereLine = n => (n === 1 ? "Once in this reading" : `${n} times in this reading`);
export const allLine = all => (all == null ? "" : all === 1 ? "Once in the Hebrew Bible, by dictionary word" : `${all} times in the Hebrew Bible, by dictionary word`);
export const stepUrl = lem => `https://www.stepbible.org/?q=version=OHB|strong=${lem}&options=HNVUG`;
export function bibleHubUrl(lem) {
  const m = /^H(\d{4})([A-Za-z]?)$/.exec(String(lem || ""));
  if (!m || /^90/.test(m[1])) return null;
  return `https://biblehub.com/hebrew/${String(Number(m[1]))}${m[2].toLowerCase()}.htm`;
}
```
