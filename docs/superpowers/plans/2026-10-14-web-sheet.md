# The web sheet (haftarah.centralreform.org) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish every delivered haftarah sheet as a native web page at `https://haftarah.centralreform.org/<slug>`, with a landing page and index at `/`, Sefaria panels for sources and Hebrew words, trope colors, dark mode and text size.

**Architecture:** A static site in `site/` (no framework, ES modules, the existing UMD `template/lib.js`) deployed by Vercel from GitHub; week data lives in a public Vercel Blob store that `scripts/publish.mjs` fills at the delivery step and the site reads same-origin through a `/data/` rewrite. `lib.js` gains a DOM-free `sheetModel()` so the web page prepares verses, keys and entries exactly as the paginator does; `render.js` and the printed sheet are untouched.

**Tech Stack:** Node 18+, zero npm dependencies, `node --test`, headless Chrome (`--dump-dom`, as `check.mjs`), Vercel static hosting + Vercel Blob REST API, Sefaria open APIs (v3 texts, words).

**Spec:** `docs/superpowers/specs/2026-10-14-web-sheet-design.md` (read it first; this plan argues from it). Reference implementation of the week page: `docs/mockups/web/mockup.html` (the approved mockup, screenshots beside it). Surface brief: `.impeccable/surfaces/site-sheet-html.md`.

## Global Constraints

- Node 18+, no npm dependencies, no `npm install`, no build tooling beyond `node scripts/*.mjs`; the site is plain HTML/CSS/ES modules served as files.
- **The printed sheet does not change.** `template/render.js`, `template/sheet.css`, `template/sheet.html`, `scripts/build.mjs`, `scripts/check.mjs` are not edited. `npm test` keeps every current test passing (one known environmental timeout in `tests/deliver.test.mjs` "CLI exits 1 …" on Daniel's machine is pre-existing).
- Week data (`weeks/`, JPS text) never enters the git repo; `site/dist/` is git-ignored; fixtures under `tests/fixtures/` hold synthetic English only.
- Tokens are never printed, logged, or put in error messages: not the drop-box token, not the Blob token.
- Design tokens (light): paper `#ffffff`, ink `#000000`, ink-2 `#595959`, frame `#4d4d4d`, rubric `#8a0a14`, reg-traditional `#8a0a14`, reg-modern `#1d4f9c`, reg-critical `#0b6a62`, reg-reference `#8a5a00`, legend-unused `#a6a6a6`. Dark: paper `#121110`, ink `#ebe6dc`, ink-2 and frame `#a8a195`, rubric and traditional `#e0616b`, modern `#86aaea`, critical `#5ec4b9`, reference `#d7b05c`, legend grey `#5c5852`. Fonts Ezra SIL (Hebrew) and Literata (Latin), Noto Serif Hebrew and Georgia as fallbacks, `font-display: swap`. Hairline rules, no border radii, no backgrounds but paper (trope backgrounds excepted).
- Root type size 17px; five text-size steps 15, 17, 19, 21, 24px; English 1rem/1.5; Hebrew 1.18em/1.75; apparatus .9rem/1.42; gloss and chrome .88rem; incipit `clamp(2.6rem, 7vw, 4.4rem)`.
- Wide layout at `min-width: 1100px` (two-track grid, 22rem rail); below it one column with Hebrew above English and the commentary in a `<details>` under the verse; the side panel is 30rem from the right on desktop and 86vh from the bottom under 640px.
- The divine name is set as יי everywhere (via `divineName`); the trope spans are always present and colored only under `html[data-trope]`; `?trope=1` wins for that load.
- Copy that the public reads (landing welcome, button labels, error lines) uses the exact strings in this plan; the welcome paragraph is shown to Daniel before it ships (section "Landing copy" below).
- Accessibility floor: every interactive thing is a `<button>` or `<a>` with a visible focus ring (`:focus-visible` outline 2px in the focus color), Escape closes whatever is open, the panel returns focus to its opener, chrome touch targets ≥ 44px, `lang="he" dir="rtl"` on Hebrew blocks, `aria-expanded` on openers, the panel `aria-hidden` when closed.
- `vercel.json` lives at the repo root (Vercel reads it from the project's root directory, which is the repo root; the spec's tree listed it under `site/`, resolved here).
- Settings (Aa) live in `site/app/settings.js`, shared by both pages (the spec folded them into `panel.js`; split so the landing page does not load the panel code).

## Review Focus

Inputs the spec implies but no task's tests would otherwise exercise; each line's test is added to the owning task.

1. A gloss whose Hebrew lemma is not found in the verse (a lemma typed with other marks, or on the divine name): the key must still appear, appended at the end of the Hebrew, never dropped. → Task 1 test "sheetModel keys a gloss whose lemma is not found by appending".
2. A commentary entry without `chapter` in a two-chapter haftarah: it attaches to the first verse with that number, as `render.js` does, not to both. → Task 1 test "sheetModel attaches a chapter-less entry to the first verse with that number".
3. `index.json` on Blob answers 200 with something that is not JSON (an HTML error page, an empty body): publish must stop with a clear error and never upload a replacement index. → Task 2 test "publish refuses a non-JSON index".
4. A Sefaria words response whose entries lack `content`, `headword` or `senses`: the word panel renders what is there and never throws. → Task 6 test "pickEntries tolerates entries without content".
5. A slug typed with a trailing slash or capitals (`/2026-10-17-Noach/`): the page loads the week (the data path is lowercase, no slash). → Task 5 test "slugFromPath normalizes case and a trailing slash".

- [ ] **Step 3: Implement** in `template/lib.js`, after `voicesFor` and before `fitIncipitSize`:

```js
  // ---- the sheet model: what any renderer (the paginator later, the web page now) draws ----

  function escapeHtml(s) {
    return String(s == null ? "" : s).replace(/[&<>"]/g, c => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;" }[c]));
  }
  // "54:1-55:5" prints "54:1–55:5"; only a dash between digits is a range.
  function enDash(s) { return String(s == null ? "" : s).replace(/(\d)-(\d)/g, "$1–$2"); }
  const paragraphs = v => Array.isArray(v) ? v.slice() : (v ? String(v).split(/\n{2,}/) : []);

  function shabbatName(data) {
    const p = (data.shabbat && data.shabbat.parashah) || {};
    const special = data.shabbat && data.shabbat.special ? `, ${String(data.shabbat.special).replace(/^Shabbat\s+/i, "")}` : "";
    return `Shabbat ${p.en || ""}${special}`;
  }

  // Everything a page draws, prepared once and DOM-free: keys assigned, the divine name set as יי,
  // gloss keys inside the Hebrew, trope phrases wrapped, entries sorted and attached to their
  // verses, the entry tails as render.js's buildEntry writes them. Status is optional; only a
  // rejected item stays off the page. The input is not changed.
  function sheetModel(data, { voices = {} } = {}) {
    const visible = item => !item || item.status !== "rejected";
    let yyCount = 0;
    const dn = html => { const r = divineName(html); yyCount += r.count; return r.html; };
    const verses = data.verses || [];

      return hit ? html.slice(0, hit.end) + mark + html.slice(hit.end) : html + mark;
```

```js
// A stub of the Blob API: records every request, serves the index it last stored.
function stubApi({ index = null, failPdf = false, badIndex = false } = {}) {
  const calls = [];
  let stored = index;
  const fetchImpl = async (url, init = {}) => {
    const u = new URL(url);
    calls.push({ method: init.method || "GET", url: String(url), headers: init.headers || {}, body: init.body });
    if (init.method === "PUT") {
      const pathname = u.searchParams.get("pathname");
      if (init.headers.authorization !== `Bearer ${TOKEN}`) return new Response(JSON.stringify({ error: { code: "forbidden" } }), { status: 403 });
      if (failPdf && pathname.endsWith(".pdf")) return new Response("busy", { status: 503 });
      if (pathname === "index.json") stored = JSON.parse(init.body);
      return new Response(JSON.stringify({ url: `${STORE}/${pathname}`, downloadUrl: `${STORE}/${pathname}?download=1`, pathname, contentType: init.headers["x-content-type"], contentDisposition: "inline", etag: "x" }), { status: 200 });
    }
    if (u.pathname === "/index.json") {
      if (badIndex) return new Response("<html>oops</html>", { status: 200 });
      return stored ? new Response(JSON.stringify(stored), { status: 200 }) : new Response("Not found", { status: 404 });
    }
    return new Response("Not found", { status: 404 });
  };
  return { calls, fetchImpl, get stored() { return stored; } };
}
```

```js
#!/usr/bin/env node
/**
 * publish.mjs — put one week on the web: its cleaned sheet.json and its PDF into the Vercel Blob
 * store the site reads, then the index of every published week.
 *
 *   node scripts/publish.mjs weeks/<slug> [--dry-run] [--token TOKEN] [--store URL] [--api URL]
 *
 * Config, first found wins: --token; HAFTARAH_BLOB_TOKEN; BLOB_READ_WRITE_TOKEN; the JSON file at
 * $HAFTARAH_WEB_CONFIG or ~/.haftarah-web.json ({"token": "..."}). The token is never printed.
 *
 * --store is the public store origin (https://<id>.public.blob.vercel-storage.com); without it the
 * origin of the first upload's url is used. --api overrides the Blob API base (tests, outages).
 */
import { readFile, access } from "node:fs/promises";
import { homedir } from "node:os";
import { basename, join, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { createRequire } from "node:module";

const L = createRequire(import.meta.url)("../template/lib.js");

export const SITE = "https://haftarah.centralreform.org";
export const BLOB_API = "https://vercel.com/api/blob";
const API_VERSION = "13";
const MAX_AGE = { json: 60, pdf: 3600 };
// Schema 2's top-level fields; anything else (candidates, drafts) stays home.
const SCHEMA2 = ["schema", "slug", "shabbat", "series", "haftarah", "verses", "glosses", "commentary", "openingNote", "glossary", "nextWeek", "credits"];

async function exists(p) { try { await access(p); return true; } catch { return false; } }
const rejected = item => item && typeof item === "object" && item.status === "rejected";

// Strip every `status` key, recursively, from a copy.
function dropStatus(value) {
  if (Array.isArray(value)) return value.map(dropStatus);
  if (value && typeof value === "object") {
    const out = {};
    for (const [k, v] of Object.entries(value)) if (k !== "status") out[k] = dropStatus(v);
    return out;
  }
  return value;
}

/** The week's data as the site shows it: no rejected items, no statuses, schema-2 fields only. */
export function cleanSheet(data) {
  const out = {};
  for (const k of SCHEMA2) if (k in data) out[k] = data[k];
  for (const k of ["commentary", "glosses", "glossary"]) if (Array.isArray(out[k])) out[k] = out[k].filter(i => !rejected(i));
  if (rejected(out.nextWeek)) out.nextWeek = null;
  return dropStatus(out);
}

/** One row of index.json. */
export function indexEntry(sheet, slug, published) {
  const s = sheet.shabbat || {}, h = sheet.haftarah || {};
  return {
    slug, civil: s.civil || "", civilDisplay: s.civilDisplay || "", hebrew: s.hebrew || "", hebrewEn: s.hebrewEn || "",
    shabbat: L.shabbatName(sheet), ref: L.enDash(h.ref || ""), book: h.book || "",
    incipit: { he: (h.incipit && h.incipit.he) || "", en: (h.incipit && h.incipit.en) || "" },
    defaultHaftarah: h.defaultHaftarah ? L.enDash(h.defaultHaftarah) : null,
    pdf: `weeks/${slug}/sheet.pdf`, published,
  };
}

/** Replace or insert the week by slug; newest civil date first. */
export function upsertIndex(index, entry, now) {
  const weeks = ((index && index.weeks) || []).filter(w => w.slug !== entry.slug);
  weeks.push(entry);
  weeks.sort((a, b) => String(b.civil).localeCompare(String(a.civil)) || String(b.slug).localeCompare(String(a.slug)));
  return { schema: 1, updated: now, weeks };
}

/** "vercel_blob_rw_<storeId>_<secret>" → storeId; anything else → null. */
export function storeIdFromToken(token) {
  const m = /^vercel_blob_rw_([A-Za-z0-9]+)_/.exec(String(token || ""));
  return m ? m[1] : null;
}

/** {token}; throws when missing. The message never contains a token. */
export async function loadWebConfig({ flags = {}, env = process.env, home = homedir() } = {}) {
  let token = flags.token || env.HAFTARAH_BLOB_TOKEN || env.BLOB_READ_WRITE_TOKEN || "";
  const file = env.HAFTARAH_WEB_CONFIG || join(home, ".haftarah-web.json");
  if (!token && (await exists(file))) {
    let cfg;
    try { cfg = JSON.parse(await readFile(file, "utf8")); }
    catch { throw new Error(`${file} is not valid JSON`); }
    token = cfg.token || "";
  }
  if (!token) {
    throw new Error(`web publishing not configured (no Blob token). Set HAFTARAH_BLOB_TOKEN, or write {"token": "..."} to ${file}. See RUNBOOK.md step 7.`);
  }
  return { token };
}

function human(n) {
  if (n < 1024) return `${n} B`;
  if (n < 1024 * 1024) return `${(n / 1024).toFixed(1)} KB`;
  return `${(n / 1024 / 1024).toFixed(2)} MB`;
}

/** PUT one blob with the headers @vercel/blob sends. Returns the API's reply (url, pathname, ...). */
export async function putBlob({ pathname, body, contentType, maxAge, token, fetchImpl = globalThis.fetch, api = BLOB_API }) {
  const headers = {
    authorization: `Bearer ${token}`,
    "x-api-version": API_VERSION,
    "x-content-type": contentType,
    "x-add-random-suffix": "0",
    "x-allow-overwrite": "1",
    "x-cache-control-max-age": String(maxAge),
    "x-vercel-blob-access": "public",
  };
  const storeId = storeIdFromToken(token);
  if (storeId) headers["x-vercel-blob-store-id"] = storeId;
  let res;
  try { res = await fetchImpl(`${api}/?pathname=${encodeURIComponent(pathname)}`, { method: "PUT", headers, body }); }
  catch (err) { throw new Error(`${pathname}: network error: ${err.cause?.code || err.message}`); }
  if (!res.ok) {
    const text = (await res.text().catch(() => "")).replace(/\s+/g, " ").slice(0, 160);
    throw new Error(`${pathname}: Blob answered HTTP ${res.status}${text ? ` (${text})` : ""}`);
  }
  const reply = await res.json().catch(() => { throw new Error(`${pathname}: Blob did not answer JSON`); });
  if (!reply.url || !String(reply.url).endsWith(`/${pathname}`)) {
    throw new Error(`${pathname}: Blob answered with an unexpected url ${reply.url || "(none)"}; expected it to end with /${pathname}`);
  }
  return reply;
}

async function fetchIndex(store, fetchImpl) {
  const url = `${store}/index.json?${Date.now()}`;   // past the CDN's copy
  let res;
  try { res = await fetchImpl(url, { method: "GET", headers: { "cache-control": "no-cache" } }); }
  catch (err) { throw new Error(`index.json: network error: ${err.cause?.code || err.message}`); }
  if (res.status === 404) return { schema: 1, weeks: [] };
  if (!res.ok) throw new Error(`index.json: Blob answered HTTP ${res.status}`);
  const text = await res.text();
  let idx;
  try { idx = JSON.parse(text); } catch { throw new Error("index.json: not JSON; the store's copy is damaged, nothing was changed"); }
  if (!idx || !Array.isArray(idx.weeks)) throw new Error("index.json: not JSON of the expected shape; nothing was changed");
  return idx;
}

/**
 * Publish the week. Returns { urls: { sheet, pdf, index }, page }. Throws on the first failure;
 * the index is uploaded last, so a failed week never changes it.
 */
export async function publish(dir, { dryRun = false, config, log = console.log, fetchImpl = globalThis.fetch, api = BLOB_API, store = null, now = () => new Date() } = {}) {
  const slug = basename(resolve(dir));
  for (const f of ["sheet.json", "sheet.pdf"]) if (!(await exists(join(dir, f)))) throw new Error(`${dir} is missing ${f}`);
  const raw = JSON.parse(await readFile(join(dir, "sheet.json"), "utf8"));
  const clean = cleanSheet(raw);
  const json = Buffer.from(JSON.stringify(clean), "utf8");
  const pdf = await readFile(join(dir, "sheet.pdf"));
  const paths = { sheet: `weeks/${slug}/sheet.json`, pdf: `weeks/${slug}/sheet.pdf`, index: "index.json" };
  const page = `${SITE}/${slug}`;
  const removed = (raw.commentary || []).filter(rejected).length;

  if (dryRun) {
    log(`web      ${paths.sheet}  (${human(json.length)}; ${clean.commentary.length} entries, ${(clean.glosses || []).length} glosses, ${(clean.glossary || []).length} glossary terms; ${removed} rejected entr${removed === 1 ? "y" : "ies"} removed)`);
    log(`web      ${paths.pdf}  (${human(pdf.length)})`);
    log(`web      ${paths.index}  (upsert ${slug})`);
    log(`Page:    ${page}`);
    return { urls: {}, page };
  }

  const token = config.token;
  const urls = {};
  const r1 = await putBlob({ pathname: paths.sheet, body: json, contentType: "application/json", maxAge: MAX_AGE.json, token, fetchImpl, api });
  urls.sheet = r1.url;
  log(`web      ${paths.sheet}  ${human(json.length)}  ${r1.url}`);
  const r2 = await putBlob({ pathname: paths.pdf, body: pdf, contentType: "application/pdf", maxAge: MAX_AGE.pdf, token, fetchImpl, api });
  urls.pdf = r2.url;
  log(`web      ${paths.pdf}  ${human(pdf.length)}  ${r2.url}`);

  const origin = store || new URL(r1.url).origin;
  const stamp = now().toISOString().replace(/\.\d{3}Z$/, "Z");
  const index = upsertIndex(await fetchIndex(origin, fetchImpl), indexEntry(clean, slug, stamp), stamp);
  const body = Buffer.from(JSON.stringify(index), "utf8");
  const r3 = await putBlob({ pathname: paths.index, body, contentType: "application/json", maxAge: MAX_AGE.json, token, fetchImpl, api });
  urls.index = r3.url;
  log(`web      ${paths.index}  ${human(body.length)}  ${r3.url}  (${index.weeks.length} week${index.weeks.length === 1 ? "" : "s"})`);
  log(`Page:    ${page}`);
  return { urls, page };
}

function parseArgs(argv) {
  const out = { flags: {} };
  for (let i = 0; i < argv.length; i++) {
    const a = argv[i];
    const m = a.match(/^--(token|store|api)(?:=(.*))?$/);
    if (m) { out.flags[m[1]] = m[2] ?? argv[++i]; continue; }
    if (a === "--dry-run") { out.dryRun = true; continue; }
    if (a.startsWith("--")) throw new Error(`unknown option ${a}`);
    if (out.dir) throw new Error(`one week folder only (got ${out.dir} and ${a})`);
    out.dir = a;
  }
  if (!out.dir) throw new Error("usage: node scripts/publish.mjs weeks/<slug> [--dry-run] [--token TOKEN] [--store URL] [--api URL]");
  return out;
}

async function main() {
  const args = parseArgs(process.argv.slice(2));
  const opts = { api: args.flags.api || process.env.HAFTARAH_BLOB_API || BLOB_API, store: args.flags.store || null };
  if (args.dryRun) { await publish(args.dir, { ...opts, dryRun: true }); return; }
  const config = await loadWebConfig({ flags: { token: args.flags.token } });
  await publish(args.dir, { ...opts, config });
}

if (process.argv[1] && fileURLToPath(import.meta.url) === resolve(process.argv[1])) {
  main().catch(err => { console.error(`publish: ${err.message}`); process.exit(1); });
}
```

```js
#!/usr/bin/env node
/**
 * web-build.mjs — assemble the static site Vercel serves: site/ plus the pieces it shares with the
 * printed sheet (lib.js, trope.css, voices.json, the fonts, the mural). Week data is not here; the
 * site reads it from the Blob store through the /data/ rewrite in vercel.json.
 *
 *   node scripts/web-build.mjs [--out DIR]     # default site/dist
 */
import { cp, mkdir, rm, readdir, copyFile } from "node:fs/promises";
import { join, resolve, dirname, relative } from "node:path";
import { fileURLToPath } from "node:url";

const ROOT = resolve(dirname(fileURLToPath(import.meta.url)), "..");

export async function buildSite({ out = join(ROOT, "site", "dist") } = {}) {
  out = resolve(out);
  await rm(out, { recursive: true, force: true });
  await mkdir(join(out, "app"), { recursive: true });
  await mkdir(join(out, "fonts"), { recursive: true });
  const files = [];
  const site = join(ROOT, "site");
  for (const name of await readdir(site)) {
    if (name === "dist") continue;
    const src = join(site, name);
    await cp(src, join(out, name), { recursive: true });
    files.push(...await listFiles(join(out, name), out));
  }
  for (const [from, to] of [["template/lib.js", "lib.js"], ["template/trope.css", "trope.css"], ["template/voices.json", "voices.json"], ["assets/logo.png", "mural.png"]]) {
    await copyFile(join(ROOT, from), join(out, to));
    files.push(to);
  }
  for (const name of await readdir(join(ROOT, "template", "fonts"))) {
    await copyFile(join(ROOT, "template", "fonts", name), join(out, "fonts", name));
    files.push(`fonts/${name}`);
  }
  return { out, files: files.sort() };
}

async function listFiles(p, base) {
  const { stat } = await import("node:fs/promises");
  if ((await stat(p)).isFile()) return [relative(base, p).split("\\").join("/")];
  const out = [];
  for (const n of await readdir(p)) out.push(...await listFiles(join(p, n), base));
  return out;
}

if (process.argv[1] && fileURLToPath(import.meta.url) === resolve(process.argv[1])) {
  const i = process.argv.indexOf("--out");
  buildSite({ out: i > 0 ? process.argv[i + 1] : undefined })
    .then(r => console.log(`Built ${r.files.length} files into ${relative(ROOT, r.out) || r.out}`))
    .catch(err => { console.error(`web-build: ${err.message}`); process.exit(1); });
}
```

```js
// Sefaria's open APIs, called from the browser (CORS open, no key). Pure helpers first, so they
// are testable in node; the two fetchers take an injectable fetch.
const SEFARIA = "https://www.sefaria.org";

export function wordForms(word, L) {
  return { vocal: L.hebrewKey(word).normalize("NFC"), consonants: L.stripMarks(word) };
}

export const joinText = t => Array.isArray(t) ? t.flat(Infinity).map(s => `<p>${s}</p>`).join("") : `<p>${t == null ? "" : t}</p>`;

export function parseText(json) {
  if (!json || json.error) throw new Error((json && json.error) || "empty answer");
  const pick = lang => { const v = (json.versions || []).find(v => v.language === lang); return v ? { html: joinText(v.text), versionTitle: v.versionTitle || "" } : null; };
  return { ref: json.ref || "", heRef: json.heRef || "", he: pick("he"), en: pick("en") };
}

export async function fetchText(ref, fetchImpl = fetch) {
  const res = await fetchImpl(`${SEFARIA}/api/v3/texts/${encodeURIComponent(ref)}?version=primary&version=translation`);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return parseText(await res.json());
}

// The lexicon answer, sorted for the panel: BDB Augmented Strong (short glosses) leads, the full BDB
// article folds, anything else is shown in full. Entries missing pieces are kept with what they have.
export function pickEntries(json) {
  const list = Array.isArray(json) ? json.filter(x => x && typeof x === "object") : [];
  const entry = x => ({ headword: x.headword || "", lexicon: x.parent_lexicon || "", morphology: (x.content && x.content.morphology) || "", senses: (x.content && Array.isArray(x.content.senses)) ? x.content.senses : [] });
  const roots = [...new Set(list.map(x => x.headword).filter(Boolean))];
  const short = list.filter(x => x.parent_lexicon === "BDB Augmented Strong").map(entry);
  const full = list.filter(x => x.parent_lexicon !== "BDB Augmented Strong").map(entry);
  return { roots, short, full };
}

export async function lookupWord(word, ref, L, fetchImpl = fetch) {
  const { vocal, consonants } = wordForms(word, L);
  const ask = async form => {
    const res = await fetchImpl(`${SEFARIA}/api/words/${encodeURIComponent(form)}?lookup_ref=${encodeURIComponent(ref)}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return res.json();
  };
  let json = await ask(vocal);
  if (!Array.isArray(json) || !json.length) json = await ask(consonants);
  return { word, vocal, consonants, ...pickEntries(json) };
}
```
