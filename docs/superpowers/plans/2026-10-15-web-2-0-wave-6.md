# Haftarah 2.0, Wave 6: the MCP server, the plugin and the engine package — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a whole week, from the calendar to the Drive folder and the live page, from any Claude surface with no local files: a remote MCP server on the haftarah Vercel project holds the credentials, the working files and the browser; a one-page skill holds the conversation; both ship as one plugin; and the engine is proved packageable for the portal.

**Architecture:** The scripts become importable functions with injected network, browser and output folder (the CLIs stay thin wrappers, so RUNBOOK.md and Claude Code keep working). `api/_lib/` holds the server's dependency-free logic, tested in Node: a Streamable HTTP MCP transport (JSON-RPC over POST, stateless), the fourteen tools, a `WeekStore` over the private Blob store (`haftarah-working`, bound to the project as `HAFTARAH_WORKING_READ_WRITE_TOKEN`) with an in-memory twin for tests, and a stateless OAuth 2.1 authorization server (every client, request, code and token is an HMAC-signed record; no database) that signs Daniel in with Google and admits only his addresses. Four Vercel functions in `api/` wrap that logic: `mcp.mjs` (the tools, with `@sparticuz/chromium` and `playwright-core` from `api/package.json`, the only dependencies in the repo), `oauth.mjs` (discovery, registration, authorize, Google callback, token, revoke), `draft.mjs` (24-hour signed downloads of a private file) and `prefetch.mjs` (the Wednesday cron). A week lives at `weeks/<slug>/…` in the private store and is materialised into `/tmp` for each tool call; the public store gets only what `deliver_week` publishes, through the unchanged `publish.mjs`; Drive stays the mirror through the unchanged drop box. `scripts/pack-engine.mjs` writes the engine as a package and a test proves a sheet built from it is the in-repo sheet.

**Tech Stack:** Node 24 on Vercel (project `nodeVersion` 24.x; Fluid compute, `maxDuration` 300, memory 3009 MB for the MCP function), the repo's dependency-free rule for everything but `api/package.json` (`@sparticuz/chromium` 153.0.0 and `playwright-core` 1.63.0, the versions CRC Overlays runs in production), `node --test`, the Vercel Blob REST API (`publish.mjs` already speaks it), Hebcal and Sefaria REST, Google OAuth 2.0 (OIDC code flow, no library), the MCP Streamable HTTP transport (2025-06-18), a Claude plugin (`.claude-plugin/plugin.json`, `.mcp.json`, `skills/`).

## Global Constraints

- Node 18+ for the scripts and tests (the machine and Vercel run 24); **no dependency anywhere but `api/package.json`**, which pins exactly `@sparticuz/chromium@153.0.0` and `playwright-core@1.63.0` with a committed `api/package-lock.json`; `api/node_modules` is git-ignored; `npm test` never needs it (nothing under `tests/` imports either package; `api/_lib/browser.mjs` imports them inside its functions with `await import()`). The root `package.json` stays dependency-free.
- **Nothing in `template/` changes.** `tests/golden/print.json` is not re-recorded; `node scripts/golden.mjs --update`, `--update-dom`, `--update-sources` and `--add` are never run. `scripts/pack-engine.mjs` copies template files; it never edits them.
- **The CLIs keep their behaviour.** Every `node scripts/<x>.mjs …` invocation in RUNBOOK.md and README.md runs as before, with the same output lines the existing tests assert; `main()` becomes a thin wrapper over the exported function.
- **No test reaches the network beyond `127.0.0.1`.** Hebcal, Sefaria, the Blob API, the drop box and Google are faked with an injected `fetchImpl` or a local `http` server; the browser is faked with an injected launcher; no test imports `api/_lib/browser.mjs`'s launch path. Any test that starts another program imports `./helpers/isolatedEnv.mjs`, calls `isolatedEnv()`, passes its `env`, and never reads `process.env`.
- **Credentials never appear in a tool result, a log line, an error message, a commit or a test file.** `HAFTARAH_WORKING_READ_WRITE_TOKEN`, `BLOB_READ_WRITE_TOKEN`, `HAFTARAH_DROPBOX_URL`, `HAFTARAH_DROPBOX_TOKEN`, `HAFTARAH_AUTH_SECRET`, `CRON_SECRET`, `GOOGLE_OAUTH_CLIENT_SECRET` are read from `process.env` only in `api/*.mjs` and passed down as an `env` object; `api/_lib/*` never reads `process.env`. Masking rule as in `publish.mjs`: an error names the store id, never the token. `tests/helpers/isolatedEnv.mjs`'s `CLEARED` list gains the five new names.
- **The private store is the record and stays private.** Working files (`sheet.json` with its rejected entries, `candidates*.json`, `texts*.json`, `prior.json`, `digest.md`, `briefing.md`, `status.json`, the PDFs, `pages/*.jpg`, `bibliography/<book>.md` overlays) live under `weeks/<slug>/` and `bibliography/` in `haftarah-working` with `x-vercel-blob-access: private`; a token whose store id is the public store's is refused before any write, and the public token is refused for a private path. Nothing from the private store is served without a bearer token or a signed, expiring URL. The public store (`wOGdAqvPmTFjKrmY`) receives only what `publish.mjs` already sends.
- **`deliver_week` runs only on Daniel's explicit go-ahead.** The tool is annotated `destructiveHint: true`, its description says so, the server's `instructions` say so, the skill says so, and it supports `dryRun`. Nothing else writes to Drive or the public store.
- **Canonical origins.** `PUBLIC_BASE_URL` (`https://haftarah.vercel.app` now) and `PUBLIC_ALTERNATE_ORIGINS` (`https://haftarah.centralreform.org`) are the only origins the server speaks as; a request from any other host is answered as the primary; the OAuth `issuer`, the protected resource `resource` and Google's `redirect_uri` are all built from the canonical origin of the request, never from the Host header alone.
- **Who may connect.** Only a Google account whose verified email is in `HAFTARAH_OWNER_EMAILS` (comma-separated) gets an authorization code; anyone else is sent back to the client with `error=access_denied`. Access tokens live 60 minutes, refresh tokens 30 days and rotate on use; a client registers with `token_endpoint_auth_method` `none`, `grant_types` `authorization_code` and `refresh_token`, `response_types` `["code"]`, up to ten `redirect_uris` that are `https:` or loopback `http:`; PKCE S256 is required; the scope is `haftarah.pipeline`, optionally with `offline_access`.

- **User-visible strings** (drafts for Daniel after the deploy, Wave 2's precedent): the server `instructions` (Task 7), the skill text (Task 7), the plugin's `description` "Make the weekly Torah and haftarah study sheets for Torah from Scratch from any Claude surface", the OAuth error page's one line "This connector is for the sheet's editor only. ## Review Focus

Inputs the spec implies that a person will meet and no task's tests would otherwise exercise; each line's test is added to the owning task.

1. **A stale `expectedVersion`** (Claude retried a save after a timeout, or two sessions touched a week): nothing is written and the answer names the current version. → Task 4 test "save_entries with a stale expectedVersion writes nothing and returns version_conflict with the current version".
2. **`deliver_week` on a week that was edited after its last build** (a text fixed, no rebuild): refused, naming the file to rebuild; never a stale PDF on Drive. → Task 5 test "deliver_week refuses a week whose status is not built or whose PDFs predate sheet.json".
3. **The wrong store's token** (the public token in the private variable, or the reverse): refused before any write, the store id named, the token never. → Task 2 test "BlobStore refuses a token for another store before any request".
4. **A Google account that is not Daniel's** (a colleague who finds the connector): no code is issued; the client gets `access_denied`; nothing is logged about the person but the outcome. → Task 2 test "the callback for an address outside HAFTARAH_OWNER_EMAILS issues no code and redirects with access_denied".
5. **A texts file bigger than a tool result** (a haftarah with twelve commentators, 1.8 MB): `get_texts` returns a slice under the cap with a `cursor`, and following the cursor to the end yields every segment once. → Task 3 test "get_texts pages a 1.8 MB texts.json under MAX_RESULT_CHARS and the cursors cover every segment exactly once".
6. **The cron fires for a Shabbat that already has a week** (Daniel started early), or without its secret: nothing is written in the first case, 401 in the second. → Task 5 tests "prefetch skips a Shabbat whose week exists" and "prefetch without the cron secret is 401".
7. **A Sefaria ref that does not resolve** (`Rashi on Isaiah 54:99`) beside a Sefaria outage: the first entry is refused and named; during an outage the entry is saved with `refUnverified` and the result says so. → Task 4 test "save_entries refuses a sourceRef Sefaria answers 404 for, and saves with a warning when Sefaria cannot be reached".
8. **A build that cannot start its browser** (the pack failed to extract, `/tmp` full): the tool answers with the gate and lint report and a named `browser` failure, not a hang or an empty 500. → Task 5 test "build_sheet whose launcher throws reports the failure in the result and leaves status drafting".

### The server's data model

```text
private store haftarah-working
  weeks/<slug>/sheet.json            the working sheet (rejected entries and statuses kept)
  weeks/<slug>/status.json           { "status": "drafting"|"built"|"delivered", "version": 7, "updatedAt": "…", "built": "…"|null, "delivered": "…"|null }
  weeks/<slug>/candidates.json, candidates-torah.json, texts.json, texts-torah.json, prior.json, digest.md, briefing.md
  weeks/<slug>/sheet.pdf, sheet-torah.pdf, sheet.html, sheet-torah.html
  weeks/<slug>/pages/haftarah-01.jpg … pages/torah-02.jpg
  bibliography/<book>.md             the overlay add_bibliography_work appends to (merged into the repo file by hand later)
```

`version` starts at 1 when `start_week` writes the sheet and goes up by one on every write to `sheet.json` or `briefing.md`; `save_entries`, `update_sheet` and `set_status` require `expectedVersion` and answer `version_conflict` with the current version when it is stale. `status` goes `drafting` → `built` (every build) → `delivered`; an edit after a build sets it back to `drafting`, and `deliver_week` refuses anything but `built`.

```js
export async function fetchTextsFor(dir, kind, { sheet = null, links = null, fetchImpl = globalThis.fetch, log = console.log, force = false } = {}) {
  const files = READING_FILES[kind];
  if (!files) throw new Error(`no texts file for a ${kind} reading`);
```

```js
/** `<kind>.<payload>.<mac>`: payload is JSON with `exp` (ms) and `iat` added. */
export function sign(secret, kind, payload, ttlMs, now = Date.now) {
  const body = b64(JSON.stringify({ ...payload, iat: now(), exp: now() + ttlMs }));
  return `${kind}.${body}.${hmac(secret, `${kind}.${body}`)}`;
}
/** The payload when the kind, the mac and the expiry hold; null otherwise. Never throws. */
export function verify(secret, kind, token, now = Date.now) {
  if (typeof token !== "string" || !secret) return null;
  const parts = token.split(".");
  if (parts.length !== 3 || parts[0] !== kind) return null;
  const expected = Buffer.from(hmac(secret, `${parts[0]}.${parts[1]}`)), given = Buffer.from(parts[2]);
  if (expected.length !== given.length || !timingSafeEqual(expected, given)) return null;
  let p; try { p = JSON.parse(unb64(parts[1])); } catch { return null; }
  if (!p || typeof p.exp !== "number" || p.exp < now()) return null;
  return p;
}

    const state = q.get("state");
    if (state && state.length > 1024) throw new Error("invalid_request");
    if (q.get("response_type") !== "code") throw new Error("unsupported_response_type");
    const challengeValue = q.get("code_challenge") || "";
    if (q.get("code_challenge_method") !== "S256" || !/^[A-Za-z0-9_-]{43}$/.test(challengeValue)) throw new Error("invalid_request");
    const scope = normalizeScope(q.get("scope"));
    const resource = `${origin}${MCP_PATH}`;
    if (q.get("resource") && q.get("resource") !== resource) throw new Error("invalid_target");
    if (!config.google || !config.owners.length) throw new Error("temporarily_unavailable");
    const nonce = random();
    const rec = sign(config.authSecret, "hr", { client: hashOpaque(q.get("client_id")), redirect_uri: redirect, code_challenge: challengeValue, scope, resource, state, nonce }, TTL.request, now);
    return { redirect: withQuery(GOOGLE_AUTH, { client_id: config.google.clientId, redirect_uri: `${origin}${GOOGLE_CALLBACK_PATH}`, response_type: "code", scope: "openid email", state: rec, nonce, prompt: "select_account", access_type: "online" }) };
  } catch (e) {
    const code = STANDARD.has(e.message) ? e.message : "server_error";
    if (verified) return { redirect: withQuery(verified, { error: code, state: q.get("state") && q.get("state").length <= 1024 ? q.get("state") : undefined }) };
    return err(code);
  }
}

  } catch { return back({ error: "temporarily_unavailable" }); }
  // Received straight from Google's token endpoint over TLS with the client secret, so the signature is
  // not checked again (OIDC Core 3.1.3.7); the claims that bind it to this request and this client are.
  const email = String(claims?.email || "").trim().toLowerCase();
  const ok = claims && GOOGLE_ISSUERS.has(claims.iss) && claims.aud === config.google.clientId && Number(claims.exp) * 1000 > now() && claims.nonce === rec.nonce && (claims.email_verified === true || claims.email_verified === "true") && config.owners.includes(email);
  if (!ok) return back({ error: "access_denied" });
  const code = sign(config.authSecret, "hcode", { client: rec.client, redirect_uri: rec.redirect_uri, code_challenge: rec.code_challenge, scope: rec.scope, resource: rec.resource, actor: email }, TTL.code, now);
  return back({ code });
}

function issue(config, now, random, { actor, scope, client, resource }, family = random()) {
  const access_token = sign(config.authSecret, "hat", { actor, scope, client, resource }, TTL.access, now);
  const refresh_token = sign(config.authSecret, "hrt", { actor, scope, client, resource, family, n: random() }, TTL.refresh, now);
  return { status: 200, body: { access_token, token_type: "Bearer", expires_in: TTL.access / 1000, refresh_token, scope } };
}
/** POST /oauth/token (form) → { status, body }. */
export async function token(form, { config, now, random = defaultRandom }) {
  const grant = form.get("grant_type");
  const clientId = form.get("client_id") || "";
  const client = verify(config.authSecret, "hc", clientId, now);
  if (!client) return err("invalid_client", 401);
  const clientHash = hashOpaque(clientId);
  if (grant === "authorization_code") {
    const c = verify(config.authSecret, "hcode", form.get("code") || "", now);
    const verifier = form.get("code_verifier") || "";
    let redirect = null; try { redirect = normalizeRedirect(form.get("redirect_uri")); } catch {}
    if (!c || c.client !== clientHash || c.redirect_uri !== redirect || !/^[A-Za-z0-9._~-]{43,128}$/.test(verifier) || pkceChallenge(verifier) !== c.code_challenge || (form.get("resource") && form.get("resource") !== c.resource)) return err("invalid_grant");
    return issue(config, now, random, c);
  }
  if (grant === "refresh_token") {
    const r = verify(config.authSecret, "hrt", form.get("refresh_token") || "", now);
    if (!r || r.client !== clientHash) return err("invalid_grant");
    return issue(config, now, random, r, r.family);
  }
  return err("unsupported_grant_type");
}

export function bearer(request, { config, now }) {
  const m = /^Bearer\s+(\S+)$/i.exec(request.headers.get("authorization") || "");
  if (!m) return null;
  const p = verify(config.authSecret, "hat", m[1], now);
  return p && p.scope && p.scope.split(" ").includes(SCOPE) ? p : null;
}
```

```js
import { createHmac, timingSafeEqual } from "node:crypto";

export const NO_STORE = { "cache-control": "no-store", "referrer-policy": "no-referrer", "x-content-type-options": "nosniff" };
export const json = (body, status = 200, headers = {}) => new Response(JSON.stringify(body), { status, headers: { "content-type": "application/json", ...NO_STORE, ...headers } });
export const text = (body, status = 200, headers = {}) => new Response(body, { status, headers: { "content-type": "text/plain; charset=utf-8", ...NO_STORE, ...headers } });

/** The body as text, refusing more than `limit` bytes (declared or read). */
export async function readLimitedBody(request, limit) {
  if (Number(request.headers.get("content-length") || 0) > limit) throw new Error("request_too_large");
  if (!request.body) return "";
  const reader = request.body.getReader(); const chunks = []; let size = 0;
  for (;;) { const { done, value } = await reader.read(); if (done) break; size += value.byteLength; if (size > limit) { await reader.cancel(); throw new Error("request_too_large"); } chunks.push(value); }
  return Buffer.concat(chunks).toString("utf8");
}
/** The origin this deployment speaks as for the request: its own when it is one of ours, else the primary. */
export function canonicalOrigin(request, origins) { const o = new URL(request.url).origin; return origins.includes(o) ? o : origins[0]; }

const sig = (secret, slug, file, exp) => createHmac("sha256", secret).update(`${slug}/${file}/${exp}`).digest("base64url");
/** A 24-hour link to one private file, served by api/draft.mjs. */
export function draftUrl(origin, secret, slug, file, now = Date.now, ttlMs = 24 * 3600_000) { const exp = now() + ttlMs; return `${origin}/api/draft/${slug}/${file}?exp=${exp}&sig=${sig(secret, slug, file, exp)}`; }
export function verifyDraft(secret, slug, file, exp, given, now = Date.now) {
  const e = Number(exp);
  if (!Number.isFinite(e) || e < now() || typeof given !== "string") return false;
  const a = Buffer.from(sig(secret, slug, file, e)), b = Buffer.from(given);
  return a.length === b.length && timingSafeEqual(a, b);
}
```

```js
// api/_lib/mcp.mjs — the MCP Streamable HTTP transport, stateless: every JSON-RPC request arrives by POST
// and is answered in one JSON response (the spec lets a server answer JSON instead of an event stream; with
// no sessions there is nothing to stream). No dependency: the four methods Claude uses are a page of code.
import { readLimitedBody, json } from "./http.mjs";
import { validateInput } from "./tools.mjs";
import { assertNoSecrets } from "./env.mjs";

export const SUPPORTED_VERSIONS = ["2025-11-25", "2025-06-18", "2025-03-26"];
export const DEFAULT_VERSION = "2025-06-18";
export const MAX_RESULT_CHARS = 120_000;
export const MAX_BODY = 1_048_576;

export const textResult = value => ({ content: [{ type: "text", text: typeof value === "string" ? value : JSON.stringify(value, null, 1) }] });
export const imageResult = (base64, mimeType, text) => ({ content: [{ type: "text", text }, { type: "image", data: base64, mimeType }] });
export const errorResult = message => ({ content: [{ type: "text", text: String(message) }], isError: true });
const rpcError = (id, code, message) => ({ jsonrpc: "2.0", id: id ?? null, error: { code, message } });
const rpcResult = (id, result) => ({ jsonrpc: "2.0", id, result });

async function dispatch(msg, { tools, instructions, serverInfo, ctx }) {
  if (!msg || msg.jsonrpc !== "2.0" || typeof msg.method !== "string") return rpcError(msg?.id, -32600, "Invalid Request");
  const { id, method, params = {} } = msg;
  if (id === undefined) return null;   // a notification: nothing to answer
  if (method === "initialize") return rpcResult(id, { protocolVersion: SUPPORTED_VERSIONS.includes(params.protocolVersion) ? params.protocolVersion : DEFAULT_VERSION, capabilities: { tools: { listChanged: false } }, serverInfo, instructions });
  if (method === "ping") return rpcResult(id, {});
  if (method === "tools/list") return rpcResult(id, { tools: tools.map(t => ({ name: t.name, description: t.description, inputSchema: t.inputSchema, annotations: t.annotations })) });
  if (method === "tools/call") {
    const tool = tools.find(t => t.name === params.name);
    if (!tool) return rpcError(id, -32602, `Unknown tool: ${params.name}`);
    const input = params.arguments && typeof params.arguments === "object" ? params.arguments : {};
    const problems = validateInput(tool.inputSchema, input);
    if (problems.length) return rpcResult(id, errorResult(problems.join("; ")));
    let result;
    try { result = await tool.handler(input, ctx); }
    catch (err) { return rpcResult(id, errorResult(err && err.message ? err.message : String(err))); }
    const wrapped = result && typeof result === "object" && Array.isArray(result.content) ? result : textResult(result);
    const size = wrapped.content.reduce((n, c) => n + (c.type === "text" ? c.text.length : 0), 0);
    if (size > MAX_RESULT_CHARS) return rpcResult(id, errorResult(`the result is too large for the client (${size} characters); narrow the request or follow a cursor`));
    try { assertNoSecrets(JSON.stringify(wrapped), ctx.config); } catch (err) { return rpcResult(id, errorResult(err.message)); }
    return rpcResult(id, wrapped);
  }
  return rpcError(id, -32601, `Method not found: ${method}`);
}

export async function handleMcp(request, opts) {
  if (request.method !== "POST") return json({ error: "method_not_allowed" }, 405, { allow: "POST" });
  let raw;
  try { raw = await readLimitedBody(request, MAX_BODY); } catch { return json({ error: "request_too_large" }, 413); }
  let body;
  try { body = JSON.parse(raw); } catch { return json(rpcError(null, -32700, "Parse error"), 400); }
  const messages = Array.isArray(body) ? body : [body];
  const answers = (await Promise.all(messages.map(m => dispatch(m, opts)))).filter(Boolean);
  if (!answers.length) return new Response(null, { status: 202, headers: { "cache-control": "no-store" } });
  return json(Array.isArray(body) ? answers : answers[0]);
}
```

```js
// api/_lib/texts.mjs — texts.json as a flat list a client can page through: every commentary segment, then
// every linked text, each with its source, kind and verse; filters by source, kind, chapter and verse; a
// cursor is the index of the next item, so pages never overlap and never skip.
const KIND = c => (c.kind || c.category || "").toLowerCase();
const verseNo = ref => { const m = /(\d+):(\d+)$/.exec(ref || ""); return m ? { chapter: +m[1], verse: +m[2] } : null; };
export function flattenTexts(texts) {
  const out = [];
  for (const [source, c] of Object.entries(texts.commentaries || {})) for (const [ref, seg] of Object.entries(c.segments || {})) out.push({ ref, source, kind: "commentary", verse: seg.verse || null, ...(seg.sectionFiled ? { sectionFiled: true } : {}), he: seg.he, ...(seg.en ? { en: seg.en } : {}) });
  for (const [ref, l] of Object.entries(texts.linked || {})) out.push({ ref, source: l.source, kind: KIND(l), anchors: l.anchors || [], he: l.he, ...(l.en ? { en: l.en } : {}) });
  return out;
}
export function sliceTexts(texts, { source = null, kind = null, chapter = null, verse = null } = {}, cursor = null, cap = 120_000) {
  const hits = v => { const n = verseNo(v); return n && (chapter == null || n.chapter === chapter) && (verse == null || n.verse === verse); };
  const items = flattenTexts(texts).filter(i => (!source || i.source.toLowerCase().includes(source.toLowerCase())) && (!kind || i.kind === kind.toLowerCase()) && (chapter == null && verse == null || (i.verse ? hits(i.verse) : (i.anchors || []).some(hits))));
  let start = Number(cursor) || 0, size = 2, end = start;
  while (end < items.length) { const n = JSON.stringify(items[end]).length + 1; if (end > start && size + n > cap) break; size += n; end++; }
  return { items: items.slice(start, end), cursor: end < items.length ? String(end) : null, total: items.length };
}
```

```js
/** A small JSON-Schema checker for the shapes the tools declare: type, required, enum, pattern, items, additionalProperties false. */
export function validateInput(schema, input, path = "") {
  const problems = [];
  const name = k => (path ? `${path}.${k}` : k);
  for (const k of schema.required || []) if (input[k] === undefined || input[k] === null) problems.push(`${name(k)} is required`);
  for (const [k, v] of Object.entries(input)) {
    const p = (schema.properties || {})[k];
    if (!p) { if (schema.additionalProperties === false) problems.push(`${name(k)} is not an input of this tool`); continue; }
    if (v === null || v === undefined) continue;
    problems.push(...checkValue(p, v, name(k)));
  }
  return problems;
}
function checkValue(p, v, where) {
  const t = p.type;
  if (t === "string" && typeof v !== "string") return [`${where} must be a string`];
  if (t === "integer" && !Number.isInteger(v)) return [`${where} must be an integer`];
  if (t === "number" && typeof v !== "number") return [`${where} must be a number`];
  if (t === "boolean" && typeof v !== "boolean") return [`${where} must be true or false`];
  if (t === "array") { if (!Array.isArray(v)) return [`${where} must be a list`]; return p.items ? v.flatMap((x, i) => checkValue(p.items, x, `${where}[${i}]`)) : []; }
  if (t === "object") { if (!v || typeof v !== "object" || Array.isArray(v)) return [`${where} must be an object`]; return validateInput(p, v, where); }
  if (p.enum && !p.enum.includes(v)) return [`${where} must be one of ${p.enum.join(", ")}`];
  if (p.pattern && typeof v === "string" && !new RegExp(p.pattern).test(v)) return [`${where} does not match ${p.pattern}`];
  if (p.maxLength && typeof v === "string" && v.length > p.maxLength) return [`${where} is longer than ${p.maxLength} characters`];

}
```

```js
// api/_lib/entries.mjs — what save_entries, update_sheet and set_status do to a sheet, as pure functions.
import { createRequire } from "node:module";
import { gate } from "../../scripts/build.mjs";
const L = createRequire(import.meta.url)("../../template/lib.js");

const clone = x => JSON.parse(JSON.stringify(x));
const readingOf = (sheet, id) => { const r = L.readings(sheet).find(x => x.id === id); if (!r) throw new Error(`no reading ${id} in this sheet`); return r; };
// Glosses have no ids in the schema; the server gives each one `id: "g-" + 8 hex` the same way, so it can be updated and rejected.
const glossId = (g, readingId) => L.entryId({ ...g, source: "gloss", sourceRef: g.lemma || "" }, readingId).replace(/^e-/, "g-");

/** Upsert commentary entries and glosses (by id; `type: "gloss"` marks a gloss) and glossary items (by term); remove by id. */
export function upsertEntries(sheet, readingId, { entries = [], glossary = [], remove = [] } = {}) {
  const out = clone(sheet);
  const r = readingOf(out, readingId);
  r.commentary = r.commentary || []; r.glosses = r.glosses || []; out.glossary = out.glossary || [];
  const touched = [];
  for (const raw of entries) {
    const { type, ...e } = raw;
    const list = type === "gloss" ? r.glosses : r.commentary;
    if (e.id) {
      const cur = list.find(x => x.id === e.id);
      if (!cur) throw new Error(`no entry ${e.id} to update in ${readingId}`);
      Object.assign(cur, e);
      touched.push(e.id);
    } else {
      const item = { ...e };
      item.id = type === "gloss" ? glossId(item, readingId) : L.entryId(item, readingId);
      let n = 2; const base = item.id;
      while (list.some(x => x.id === item.id)) item.id = `${base}-${n++}`;
      list.push(item);
      touched.push(item.id);
    }
  }
  let glossaryTouched = 0;
  for (const g of glossary) { const i = out.glossary.findIndex(x => x.term === g.term); if (i >= 0) out.glossary[i] = { ...out.glossary[i], ...g }; else out.glossary.push(g); glossaryTouched++; }
  for (const id of remove) { r.commentary = r.commentary.filter(x => x.id !== id); r.glosses = r.glosses.filter(x => x.id !== id); }
  return { sheet: out, touched, glossaryTouched };
}

/** The citation gate's problems for the touched entries, keyed by id ([] when clean). */
export function validateEntries(sheet, readingId, ids, { biblio = null } = {}) {
  const view = L.readingView(sheet, readingId);
  const problems = gate(view, biblio);
  const r = readingOf(sheet, readingId);
  const out = new Map();
  for (const id of ids) {
    const e = (r.commentary || []).find(x => x.id === id);
    if (!e) { out.set(id, []); continue; }   // a gloss: lint covers it
    const where = `${e.chapter ? e.chapter + ":" : ""}${e.verse} ${e.source}`;
    out.set(id, problems.filter(p => p.endsWith(where) || p.includes(`(${where})`)));
  }
  return out;
}

/** Ask Sefaria whether each ref resolves (one call per distinct ref): ok / missing / unknown (could not ask). */
export async function verifyRefs(refs, { fetchImpl = globalThis.fetch } = {}) {
  const out = new Map();
  for (const ref of refs) {
    if (!ref || out.has(ref)) continue;
    try {
      const res = await fetchImpl(`https://www.sefaria.org/api/v3/texts/${encodeURIComponent(ref)}?return_format=default`, { headers: { accept: "application/json" }, signal: AbortSignal.timeout(8000) });
      if (res.status === 404 || res.status === 400) { out.set(ref, "missing"); continue; }
      if (!res.ok) { out.set(ref, "unknown"); continue; }
      const j = await res.json().catch(() => null);
      out.set(ref, j && !j.error && Array.isArray(j.versions) && j.versions.length ? "ok" : "missing");
    } catch { out.set(ref, "unknown"); }
  }
  return out;
}

const PATCHABLE = ["openingNote", "glossary", "nextWeek", "credits", "highlights", "places", "mapRegion", "timeline"];
/** JSON-merge the allowed keys (objects merge one level, lists and scalars replace) and each reading's incipit. */
export function applyPatch(sheet, patch) {
  const out = clone(sheet), changed = [];
  for (const [k, v] of Object.entries(patch || {})) {
    if (k === "readings") {
      for (const [id, rp] of Object.entries(v || {})) {
        const r = readingOf(out, id);
        for (const [rk, rv] of Object.entries(rp || {})) { if (rk !== "incipit") throw new Error(`readings.${id}.${rk}: only incipit can be patched on a reading`); r.incipit = { ...(r.incipit || {}), ...rv }; changed.push(`readings.${id}.incipit`); }
      }
      continue;
    }
    if (!PATCHABLE.includes(k)) throw new Error(`${k} cannot be patched; use save_entries for entries and glosses`);
    out[k] = v && typeof v === "object" && !Array.isArray(v) && out[k] && typeof out[k] === "object" && !Array.isArray(out[k]) ? { ...out[k], ...v } : v;
    changed.push(k);
  }
  return { sheet: out, changed };
}

/** status "rejected" or null on commentary entries and glosses, by id, in any reading. */
export function setStatuses(sheet, ids, status) {
  const out = clone(sheet); let changed = 0;
  for (const id of ids) {
    const item = L.readings(out).flatMap(r => [...(r.commentary || []), ...(r.glosses || [])]).find(x => x.id === id);
    if (!item) throw new Error(`no entry ${id} in this sheet`);
    if (status) item.status = status; else delete item.status;
    changed++;
  }
  return { sheet: out, changed };
}
```

```js
// api/_lib/browser.mjs — where the browser comes from. On Vercel it is @sparticuz/chromium's pack: spawned
// with build.mjs's flags for the PDFs (the same path as a local build, so the pagination is the pagination
// the print golden guards) and driven by playwright-core for the page images (a headless --screenshot on
// Linux loses the bottom of the page). Both packages are imported here and only here, lazily, so the rest
// of the server and every test run without them.
import { join } from "node:path";
import { mkdir } from "node:fs/promises";
import { browserRecord, findBrowser } from "../../scripts/build.mjs";
import { screenshot } from "../../scripts/chrome.mjs";

export const PAGE = { width: 816, height: 1056, quality: 70 };
const pad = n => String(n).padStart(2, "0");

export async function vercelLauncher() {
  const pack = (await import("@sparticuz/chromium")).default;
  const path = await pack.executablePath();
  const extraArgs = [...pack.args.filter(a => !a.startsWith("--headless") && !a.startsWith("--user-data-dir") && !a.startsWith("--window-size")), "--no-sandbox"];
  return {
    browser: browserRecord(path, extraArgs),
    async pages(url, outDir, count, prefix) {
      const { chromium } = await import("playwright-core");
      await mkdir(outDir, { recursive: true });
      const b = await chromium.launch({ executablePath: path, args: pack.args, headless: true });
      try {
        const page = await b.newPage({ viewport: { width: PAGE.width, height: PAGE.height }, deviceScaleFactor: 1 });
        const names = [];
        for (let p = 1; p <= count; p++) {
          await page.goto(`${url}?page=${p}`, { waitUntil: "load" });
          await page.waitForFunction(() => !!document.documentElement.dataset.pages, null, { timeout: 30_000 });
          await page.evaluate(() => document.fonts.ready);
          const name = `${prefix}-${pad(p)}.jpg`;
          await page.screenshot({ path: join(outDir, name), type: "jpeg", quality: PAGE.quality, clip: { x: 0, y: 0, ...PAGE } });
          names.push(name);
        }
        return names;
      } finally { await b.close().catch(() => {}); }
    },
  };
}

/** This machine's Chrome or Edge, for a build driven from Claude Code: the PDFs as build.mjs makes them, the page images as PNG screenshots renamed .jpg is wrong, so they stay PNG and the tool reports their type. */
export async function localLauncher() {
  const path = findBrowser();
  if (!path) throw new Error("No Chrome or Edge found on this machine");
  return {
    browser: browserRecord(path),
    async pages(url, outDir, count, prefix) {
      await mkdir(outDir, { recursive: true });
      const names = [];
      for (let p = 1; p <= count; p++) { const name = `${prefix}-${pad(p)}.png`; await screenshot(path, `${url}?page=${p}`, { size: `${PAGE.width},${PAGE.height}`, out: join(outDir, name) }); names.push(name); }
      return names;
    },
  };
}
```

```js
// api/oauth.mjs — discovery, registration, authorize (to Google), the Google callback, token, revoke. Reached
// through vercel.json's rewrites, which carry the action in the query and keep the client's own parameters.
import { configFrom } from "./_lib/env.mjs";
import { metadata, resourceMetadata, register, authorize, googleCallback, token } from "./_lib/oauth.mjs";
import { canonicalOrigin, json, text, readLimitedBody } from "./_lib/http.mjs";

const MAX_OAUTH_BODY = 16_384;
const ACTION_BY_PATH = { "/.well-known/oauth-authorization-server": "metadata", "/.well-known/oauth-protected-resource": "resource", "/oauth/authorize": "authorize", "/oauth/token": "token", "/oauth/register": "register", "/oauth/revoke": "revoke", "/api/auth/google/callback": "callback" };
export const EDITOR_ONLY = "This connector is for the sheet's editor only. Sign in with the account that edits the sheet, or close this window.";

export function createOauthApp(env, { fetchImpl = globalThis.fetch, now = () => Date.now(), random = undefined } = {}) {
  return async request => {
    const config = configFrom(env);
    if (!config.authSecret) return json({ error: "server_not_configured", missing: ["HAFTARAH_AUTH_SECRET"] }, 503);
    const origin = canonicalOrigin(request, config.origins);
    const url = new URL(request.url);
    const action = url.searchParams.get("action") || Object.entries(ACTION_BY_PATH).find(([p]) => url.pathname === p || url.pathname.startsWith(p + "/"))?.[1];
    url.searchParams.delete("action");
    const canonical = new URL(`${origin}${url.pathname}${url.search}`);
    const ctx = { config, now, fetchImpl, ...(random ? { random } : {}) };
    const answer = r => (r.redirect ? Response.redirect(r.redirect, r.status === 303 ? 303 : 302) : json(r.body, r.status));
    switch (action) {
      case "metadata": return json(metadata(origin), 200, { "access-control-allow-origin": "*" });
      case "resource": return json(resourceMetadata(origin), 200, { "access-control-allow-origin": "*" });
      case "register": {
        if (request.method !== "POST" || !(request.headers.get("content-type") || "").toLowerCase().startsWith("application/json")) return json({ error: "invalid_client_metadata" }, 400);
        let body; try { body = JSON.parse(await readLimitedBody(request, MAX_OAUTH_BODY)); } catch { return json({ error: "invalid_client_metadata" }, 400); }
        return answer(await register(body, ctx));
      }
      case "authorize": return request.method === "GET" ? answer(await authorize(canonical, ctx)) : json({ error: "invalid_request" }, 405);
      case "callback": {
        const r = await googleCallback(canonical, ctx);
        return r.redirect ? Response.redirect(r.redirect, 303) : text(EDITOR_ONLY, r.status || 400);
      }
      case "token": {
        if (request.method !== "POST" || !(request.headers.get("content-type") || "").toLowerCase().startsWith("application/x-www-form-urlencoded")) return json({ error: "invalid_request" }, 400);
        let form; try { form = new URLSearchParams(await readLimitedBody(request, MAX_OAUTH_BODY)); } catch { return json({ error: "invalid_request" }, 413); }
        return answer(await token(form, ctx));
      }
      case "revoke": return request.method === "POST" ? json({}, 200) : json({ error: "invalid_request" }, 405);
      default: return json({ error: "not_found" }, 404);
    }
  };
}
export default request => createOauthApp(process.env)(request);
```

```js
 * pack-engine.mjs — the engine (spec 3.1) as a dependency-free package the B'nei Mitzvah portal can install:

import { cp, mkdir, rm, readFile, writeFile, readdir } from "node:fs/promises";
import { createHash } from "node:crypto";
import { join, resolve, relative, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const ROOT = resolve(dirname(fileURLToPath(import.meta.url)), "..");
export const ENGINE_FILES = ["lib.js", "render.js", "sheet.html", "sheet.css", "trope.css", "voices.json"];

export async function packEngine(out, { root = ROOT, version = "2.0.0" } = {}) {
  await rm(out, { recursive: true, force: true });
  await mkdir(out, { recursive: true });
  for (const f of ENGINE_FILES) await cp(join(root, "template", f), join(out, f));

  const files = [];
  for (const p of (await walk(out)).sort()) files.push({ path: relative(out, p).split("\\").join("/"), sha256: createHash("sha256").update(await readFile(p)).digest("hex") });
  const pkg = {
    name: "@haftarah/engine", version, private: false,
    description: "The haftarah sheet engine: the data model and its accessors, keys, divine name, trope phrases, the sheet model, the print paginator, the page template, stylesheets and fonts. Dependency-free; a UMD lib.js for Node and the browser.",
    main: "lib.js",

    engines: { node: ">=18" },

  };
```
