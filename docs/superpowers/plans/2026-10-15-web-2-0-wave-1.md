**Goal:** Make every later 2.0 change safe (a print golden, browser checks and test isolation in `npm test`, a Content-Security-Policy, accessibility fixes, one contract module), move the data model to schema 3 `readings[]` behind back-compatible accessors with stable ids, and ship the first study features for remote learners: verse links, copy with citation, a Hebrew/English/both switch, teacher highlights, a pluggable analytics hook, and the presenter view.

## Global Constraints

- Node 18+, no npm dependencies, no `npm install`, no build tooling beyond `node scripts/*.mjs`; the site is plain HTML/CSS/ES modules served as files, no framework.
- **The printed sheet stays byte-identical for schema-2 data.** `template/render.js`, `template/sheet.css`, `template/sheet.html` and the fonts are not edited. `template/lib.js` gains functions only; no existing function changes behavior. `scripts/build.mjs` reads data only through `readingView`, which returns a schema-2 file as the same object. The print golden (Task 1) must stay green in every later task; it is never re-recorded in Wave 1.
- Week data (`weeks/`, JPS text) never enters the repo. Fixtures and test strings are synthetic; never paste JPS English into a test, a fixture, a doc or a commit.
- Tokens are never printed, logged, or put in error messages or test output.
- **Test isolation:** any test file that starts another program (child_process, or `buildFixture` from `scripts/golden.mjs`) imports `./helpers/isolatedEnv.mjs`, calls `isolatedEnv()`, passes its `env`, and never reads `process.env`. No test reaches the network beyond `127.0.0.1`.

- No inline `<script>` and no `style` attribute anywhere in `site/` (the CSP forbids both); script-set positions use the CSSOM (`el.style.left = …`, `el.style.setProperty(…)`), which the policy allows.
- Accessibility floor: every interactive thing is a `<button>` or `<a>` (or a `role="button"` word span with a roving tabindex), with a visible focus ring; Escape closes whatever is open; chrome touch targets at least 44px (2.75rem); `lang="he" dir="rtl"` on Hebrew; `aria-expanded` on openers; color is never the only signal.

- Device storage keys are `haftarah:v1:<name>`; every storage access is wrapped so a throwing or missing `localStorage` changes nothing but persistence.
- Analytics carry only the allow-listed properties (Task 11); the shipped provider is `none`.
- User-visible strings are exactly the ones in this plan: "Show", "Hebrew", "Both", "English", "Copy link", "Copy verse", "Copied", "Not copied", "Highlighted." import assert from "node:assert/strict";
```js
import { EventEmitter } from "node:events";
import { PassThrough } from "node:stream";
import { dumpDom, parseBrowserVersion, printSignature, sha256 } from "../scripts/chrome.mjs";

// A stand-in for a spawned Chrome: `script(child)` decides what it writes and when it exits.
function fakeSpawn(script) {
  const calls = [];
  const spawnImpl = (cmd, args) => {
    const child = new EventEmitter();
    child.stdout = new PassThrough(); child.stderr = new PassThrough();
    child.killed = false;
    child.kill = () => { child.killed = true; setTimeout(() => child.emit("close", null), 5); return true; };
    calls.push({ cmd, args, child });
    setImmediate(() => script(child));
    return child;
  };
  return { spawnImpl, calls };
}

test("dumpDom decodes UTF-8 once, so a chunk boundary inside a Hebrew letter is harmless", async () => {
  const body = Buffer.from("<html><body>שָׁלוֹם</body></html>", "utf8");
  const { spawnImpl, calls } = fakeSpawn(child => {
    child.stdout.write(body.subarray(0, 13));   // "<html><body>" is 12 bytes; byte 13 is the first half of ש
    child.stdout.write(body.subarray(13));
    child.stdout.end();
    setTimeout(() => child.emit("close", 0), 20);
  });
  const dom = await dumpDom("chrome", "file:///x.html", { size: "1440,900", spawnImpl });
  assert.equal(dom, "<html><body>שָׁלוֹם</body></html>");
  assert.ok(calls[0].args.includes("--window-size=1440,900"));
  assert.ok(calls[0].args.includes("--dump-dom"));
  assert.equal(calls[0].args.at(-1), "file:///x.html");
});

test("dumpDom kills a Chrome that does not finish", async () => {
  const { spawnImpl, calls } = fakeSpawn(() => {});   // never writes, never exits
  await assert.rejects(dumpDom("chrome", "file:///hang.html", { timeoutMs: 50, spawnImpl }), /did not finish file:\/\/\/hang\.html within 50ms; killed/);
  assert.equal(calls[0].child.killed, true);
});

test("dumpDom reports Chrome's exit code and the end of its stderr", async () => {
  const { spawnImpl } = fakeSpawn(child => { child.stderr.write("GPU process crashed"); child.stderr.end(); setTimeout(() => child.emit("close", 21), 10); });
  await assert.rejects(dumpDom("chrome", "file:///x.html", { spawnImpl }), /dump-dom exited 21[\s\S]*GPU process crashed/);
});

test("parseBrowserVersion names Chrome, and Edge when it is Edge", () => {
  assert.equal(parseBrowserVersion("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) HeadlessChrome/155.0.0.0 Safari/537.36"), "HeadlessChrome/155.0.0.0");
```

```js
#!/usr/bin/env node
/**
 * chrome.mjs — the one way the scripts read a page rendered by headless Chrome: check.mjs (the
 * printed layout), web-check.mjs (the site) and golden.mjs (the print golden).
 *
 * dumpDom collects Chrome's output as bytes and decodes it once at the end: decoding chunk by chunk
 * breaks a Hebrew letter whose two bytes straddle a chunk boundary. It kills a Chrome that does not
 * finish in time instead of hanging the check.
 */
import { spawn } from "node:child_process";
import { mkdir, rm } from "node:fs/promises";
import { join } from "node:path";
import { tmpdir } from "node:os";
import { createHash } from "node:crypto";
import { chromeFlags } from "./build.mjs";

export const DUMP_TIMEOUT_MS = 90_000;
const span = ms => (ms >= 1000 ? `${Math.round(ms / 1000)}s` : `${ms}ms`);

/** The DOM after the page's scripts ran. `size` ("1440,900") sets the window. */
export async function dumpDom(browser, url, { size = null, timeoutMs = DUMP_TIMEOUT_MS, spawnImpl = spawn } = {}) {
  const profile = join(tmpdir(), `haftarah-dom-${process.pid}-${Math.random().toString(36).slice(2)}`);
  await mkdir(profile, { recursive: true });
  const args = [...chromeFlags(profile), ...(size ? [`--window-size=${size}`] : []), "--dump-dom", url];
  try {
    return await new Promise((resolve, reject) => {
      const child = spawnImpl(browser, args, { stdio: ["ignore", "pipe", "pipe"] });
      const out = [], err = [];
      let timedOut = false;
      child.stdout.on("data", d => out.push(Buffer.from(d)));
      child.stderr.on("data", d => err.push(Buffer.from(d)));
      const timer = setTimeout(() => { timedOut = true; child.kill(); }, timeoutMs);
      child.on("error", e => { clearTimeout(timer); reject(e); });
      child.on("close", code => {
        clearTimeout(timer);
        if (timedOut) return reject(new Error(`Chrome did not finish ${url} within ${span(timeoutMs)}; killed`));
        if (code !== 0) return reject(new Error(`dump-dom exited ${code}\n${Buffer.concat(err).toString("utf8").slice(-500)}`));
        resolve(Buffer.concat(out).toString("utf8"));
      });
    });
  } finally {
    await rm(profile, { recursive: true, force: true }).catch(() => {});
  }
}

/** "HeadlessChrome/155.0.0.0", plus "Edg/…" for Edge, from a user agent or a page that shows one. */
export function parseBrowserVersion(text) {
  const chrome = /(?:Headless)?Chrome\/[\d.]+/.exec(text || ""), edge = /Edg\/[\d.]+/.exec(text || "");
  return [chrome && chrome[0], edge && edge[0]].filter(Boolean).join(" ") || "unknown";
}

export async function browserVersion(browser, opts = {}) {
  const page = "data:text/html,<body><script>document.body.textContent=navigator.userAgent</script></body>";
  return parseBrowserVersion(await dumpDom(browser, page, opts));
}

/** What prints, as one string: the <html> tag render.js stamps (pages, keys, divine-name count) and the whole sheet. */
export function printSignature(dom) {
  const root = (String(dom).match(/<html[^>]*>/) || [""])[0];
  const main = (String(dom).match(/<main id="sheet"[\s\S]*?<\/main>/) || [""])[0];
  return `${root}\n${main}`;
}

export const sha256 = s => createHash("sha256").update(String(s), "utf8").digest("hex");
```

```js
// The one way a test runs another program. The child's environment is built from an allow-list:
// HOME and USERPROFILE point into a fresh temp folder (on Windows os.homedir() reads USERPROFILE,
// which is how a 2026-10-14 test delivered the fixture to the real Drive and Blob), the drop-box and
// web config paths point at files that do not exist, and no token variable is passed on. A test that
// needs one (for a local fake server) passes it in `extra`.
import { mkdtemp, rm } from "node:fs/promises";
import { tmpdir } from "node:os";
import { join } from "node:path";

// Kept from the parent, matched case-insensitively: what Node and Chrome need to start, and the browser pin.
const PASS = new Set(["PATH", "SYSTEMROOT", "WINDIR", "TEMP", "TMP", "LOCALAPPDATA", "PROGRAMFILES", "PROGRAMFILES(X86)", "HAFTARAH_BROWSER"]);
// Never passed on, whatever the parent has.
export const CLEARED = ["HAFTARAH_BLOB_TOKEN", "HAFTARAH_DROPBOX_URL", "HAFTARAH_DROPBOX_TOKEN", "BLOB_READ_WRITE_TOKEN"];

export async function isolatedEnv(extra = {}) {
  const home = await mkdtemp(join(tmpdir(), "haftarah-home-"));
  const env = {};
  for (const [k, v] of Object.entries(process.env)) if (PASS.has(k.toUpperCase())) env[k] = v;
  Object.assign(env, {
    HOME: home, USERPROFILE: home,
    HAFTARAH_DROPBOX_CONFIG: join(home, "no-dropbox.json"),
    HAFTARAH_WEB_CONFIG: join(home, "no-web.json"),
  }, extra);
  return { env, home, cleanup: () => rm(home, { recursive: true, force: true }) };
}
```

```js
/**

 * build, the template, render.js, lib.js or the fonts cannot reach a printed sheet unnoticed.
 *
 *   node scripts/golden.mjs            # compare with tests/golden/print.json (npm test does this too)
```

```js
// Keyboard and focus helpers. The pure parts are tested in node; the DOM parts are exercised by
// web-check's ?check=1 run.

/** Roving focus among a verse's words. Hebrew runs right to left, so ArrowLeft reads on. */
export function rovingTarget(index, count, key) {
  if (!count) return null;
  switch (key) {
    case "ArrowLeft": return Math.min(count - 1, index + 1);
    case "ArrowRight": return Math.max(0, index - 1);
    case "Home": return 0;
    case "End": return count - 1;
    default: return null;
  }
}

/** Tab inside a dialog: the index to focus instead, wrapping at either end; null leaves it to the browser. */
export function trapTarget(index, count, shift) {
  if (!count) return null;
  if (shift && index <= 0) return count - 1;
  if (!shift && index >= count - 1) return 0;
  return null;
}

/** One tab stop per container: the first item (or the one last focused) is in the tab order; arrows move among the rest. */
export function initRoving(container, selector) {
  const items = () => [...container.querySelectorAll(selector)];
  items().forEach((w, i) => { w.tabIndex = i === 0 ? 0 : -1; });
  container.addEventListener("keydown", e => {
    const list = items(), i = list.indexOf(e.target);
    if (i < 0) return;
    const j = rovingTarget(i, list.length, e.key);
    if (j == null) return;
    e.preventDefault();
    if (j === i) return;
    list[i].tabIndex = -1; list[j].tabIndex = 0; list[j].focus();
  });
  container.addEventListener("focusin", e => {
    const list = items();
    if (list.includes(e.target)) list.forEach(w => { w.tabIndex = w === e.target ? 0 : -1; });
  });
}

const FOCUSABLE = 'a[href], button:not([disabled]), input:not([disabled]), [tabindex]:not([tabindex="-1"])';
export const focusables = root => [...root.querySelectorAll(FOCUSABLE)].filter(n => !n.closest("[hidden]"));

/** Keep Tab inside `host` while isOpen() is true. */
export function trapFocus(host, isOpen) {
  host.addEventListener("keydown", e => {
    if (e.key !== "Tab" || !isOpen()) return;
    const list = focusables(host), j = trapTarget(list.indexOf(document.activeElement), list.length, e.shiftKey);
    if (j != null) { e.preventDefault(); list[j].focus(); }
  });
}
```

```js
// Per-device preferences under one prefix, so later features (a reader's own highlights, the offline
// app) cannot collide with them. Every access is guarded: a private window or blocked site data
// throws, and the page must work the same without storage.
export const PREFIX = "haftarah:v1:";
const LEGACY = ["size", "theme", "trope"];   // the unprefixed keys of the first web release (2026-10-14)

export const key = name => PREFIX + name;
const storageOf = s => s || globalThis.localStorage;

export function load(name, storage) {
  try { return storageOf(storage).getItem(key(name)); } catch { return null; }
}

export function store(name, value, storage) {
  try { const s = storageOf(storage); value == null ? s.removeItem(key(name)) : s.setItem(key(name), String(value)); } catch {}
}

/** Move the legacy keys under the prefix once; a value already under the prefix wins. Returns the names moved. */
export function migrateKeys(storage) {
  const moved = [];
  try {
    const s = storageOf(storage);
    for (const name of LEGACY) {
      const old = s.getItem(name);
      if (old == null) continue;
      if (s.getItem(key(name)) == null) { s.setItem(key(name), old); moved.push(name); }
      s.removeItem(name);
    }
  } catch {}
  return moved;
}
```

```js
  // A week may carry more than one reading: the haftarah, and from Wave 2 a Torah selection. A
  // schema-2 file is one haftarah reading. These accessors let every caller treat both shapes alike;
  // readingView gives the print and the scripts the schema-2 shape they have always read, and gives
  // a schema-2 file back untouched, which is what keeps its print byte-identical.

  // Keys that belong to a reading but not to the schema-2 "haftarah" object.
  const READING_OWN = ["id", "kind", "verses", "glosses", "commentary", "aliyot", "selection", "maftir"];

  function readings(data) {
    if (!data) return [];
    if (Number(data.schema) >= 3) return Array.isArray(data.readings) ? data.readings : [];
    return [Object.assign({ id: "haftarah", kind: "haftarah" }, data.haftarah || {},
      { verses: data.verses || [], glosses: data.glosses || [], commentary: data.commentary || [] })];
  }

  // The reading the week is known by: its haftarah, else its first reading.
  function primaryReading(data) {
    const all = readings(data);
    return all.find(r => r.kind === "haftarah") || all[0] || null;
  }

  // One reading in the schema-2 shape. A schema-2 file comes back as the same object. For schema 3
  // the verses lose `book` and the entries lose `id` (the print never read them); the glosses array
  // is the reading's own, so a fix written into the view (lint --fix) lands in the file.
  function readingView(data, readingId) {
    if (!data || Number(data.schema) < 3) return data;
    const all = readings(data);
    const r = readingId ? all.find(x => x.id === readingId) : primaryReading(data);
    if (!r) throw new Error(readingId ? `no reading "${readingId}" in this sheet` : "this sheet has no readings");
    const haftarah = {};
    for (const [k, v] of Object.entries(r)) if (!READING_OWN.includes(k)) haftarah[k] = v;
    const view = {
      schema: 2, slug: data.slug, shabbat: data.shabbat, series: data.series, haftarah,
      verses: (r.verses || []).map(({ book, ...v }) => v),

    for (const k of Object.keys(view)) if (view[k] === undefined) delete view[k];
    return view;

  function parashahKey(name) {

  // from where the entry sits and what it cites when it is first given, so the same file always gets

  function entryId(e, readingId) {
```

```js
/** A verse's address on its week page: <reading>-<chapter>-<verse>, e.g. haftarah-54-3. */
export const verseAnchor = (readingId, chapter, verse) => `${readingId}-${chapter}-${verse}`;

/**
 * "#haftarah-54-3" → { reading: "haftarah", chapter: 54, verse: 3 }. The first release's "#v54-3"
 * → { reading: null, … } (the page maps it to its primary reading). Anything else → null.
 */
export function parseVerseAnchor(hash) {
  const h = String(hash == null ? "" : hash).replace(/^#/, "");
  let m = /^([a-z][a-z0-9]*)-(\d{1,3})-(\d{1,3})$/.exec(h);
  if (m && m[1] !== "v") return { reading: m[1], chapter: Number(m[2]), verse: Number(m[3]) };
  m = /^v(\d{1,3})-(\d{1,3})$/.exec(h);
  return m ? { reading: null, chapter: Number(m[1]), verse: Number(m[2]) } : null;
}
```

```js
export function citationText({ he, en, ref, translation, url, mode = "both" }) {
  const lines = [];
  if (mode !== "en" && he) lines.push(he);
  if (mode !== "he" && en) lines.push(en);

export function highlightsFor(list, readingId, chapter, verse) {
  return (Array.isArray(list) ? list : []).filter(h => h && (h.reading || "haftarah") === readingId && Number(h.chapter) === chapter && Number(h.verse) === verse);

// A highlight's [first, last] word (0-based, inclusive) cut to a verse of `count` words; null when nothing of it is in the verse.
export function wordRange(words, count) {
  if (!Array.isArray(words) || words.length !== 2 || !count) return null;
  const [a, b] = words;
  if (!Number.isInteger(a) || !Number.isInteger(b) || a > b || b < 0 || a >= count) return null;
  return [Math.max(0, a), Math.min(count - 1, b)];
}
```

```js
// Aggregate counts only: which verses are viewed, which sources opened, how many words are looked up,
// presenter starts, installs. No identifiers, no cookies, no storage, never the word a reader looked up,
// never the query or the verse fragment of the address. Do Not Track or Global Privacy Control turns it off.
import CONFIG from "./analytics-config.js";

// Every event the page may send, and the only properties each may carry.
export const EVENTS = {
  verse_view: ["week", "verse"],
  source_open: ["week", "source"],
  word_lookup: ["week"],
  present_start: ["week"],
  install: [],
};

/** An event's data: its allow-listed properties only, as strings of at most 120 characters; null for an unknown event. */
export function eventData(name, props = {}) {
  const keys = EVENTS[name];
  if (!keys) return null;
  const out = {};
  for (const k of keys) if (props && props[k] != null) out[k] = String(props[k]).slice(0, 120);
  return out;
}

export const optedOut = nav => !!nav && (nav.doNotTrack === "1" || nav.globalPrivacyControl === true);

/** The body Umami's /api/send takes for one event. */
export function umamiBody(config, name, data, loc) {
  return { type: "event", payload: { website: config.websiteId, hostname: loc.hostname, url: loc.pathname, name, data } };
}

export function createAnalytics(config = CONFIG, { fetchImpl = globalThis.fetch, nav = globalThis.navigator, loc = globalThis.location } = {}) {
  const on = config && config.provider === "umami" && config.websiteId && config.endpoint && !optedOut(nav);
  const seen = new Set();
  function send(name, data) {
    try {
      const p = fetchImpl(config.endpoint, { method: "POST", keepalive: true, headers: { "content-type": "application/json" }, body: JSON.stringify(umamiBody(config, name, data, loc)) });
      if (p && typeof p.catch === "function") p.catch(() => {});
    } catch {}
  }
  function track(name, props) {
    const data = eventData(name, props);
    if (!on || !data) return false;
    if (name === "verse_view") { const k = `${data.week}|${data.verse}`; if (seen.has(k)) return false; seen.add(k); }
    send(name, data);
    return true;
  }
  return { track, provider: on ? "umami" : "none" };
}
```

```js
// Presenter view (?present): one verse at a time, large, for a laptop sharing its screen on Zoom.
// A presenter remote sends PageDown and PageUp; the keyboard has the rest. The current verse is in
// the address, so a reload resumes and the link can be pasted into the chat.
import { parseVerseAnchor } from "./contract.js";

export const PRESENT_KEYS = {
  PageDown: "next", ArrowRight: "next", ArrowDown: "next", " ": "next", Enter: "next",
  PageUp: "prev", ArrowLeft: "prev", ArrowUp: "prev", Backspace: "prev",
  Home: "first", End: "last",
  b: "blank", B: "blank", ".": "blank",
  c: "notes", C: "notes", n: "preview", N: "preview", t: "trope", T: "trope",
  "+": "bigger", "=": "bigger", "-": "smaller", _: "smaller",
  "?": "help", Escape: "exit",
};

/** What a key does here, or null to leave it to the browser (zoom, history, a focused button). */
export function presentAction({ key, ctrlKey = false, metaKey = false, altKey = false, onControl = false }) {
  if (ctrlKey || metaKey || altKey) return null;
  if (onControl && (key === " " || key === "Enter")) return null;
  return PRESENT_KEYS[key] || null;
}

export function stepIndex(i, n, action) {
  if (!n) return 0;
  if (action === "next") return Math.min(n - 1, i + 1);
  if (action === "prev") return Math.max(0, i - 1);
  if (action === "first") return 0;
  if (action === "last") return n - 1;
  return i;
}

export const isPresent = search => new URLSearchParams(search || "").has("present");

/** The verse to start on: the one in the address (an old #v-anchor included), else the first. */
export function startIndex(rows, hash) {
  const a = parseVerseAnchor(hash);
  if (!a) return 0;
  const i = rows.findIndex(r => r.chapter === a.chapter && r.verse === a.verse && (a.reading == null || a.reading === r.reading));
  return i < 0 ? 0 : i;
}

/** The verse without its footnote and gloss letters: they mean nothing on a shared screen. */
export const stripKeys = html => String(html == null ? "" : html).replace(/<sup class="fn(?: he)?">[a-z]+<\/sup>/g, "");

export function initPresent({ model, rows, L, track = () => {}, onExit = () => {} }) {
  const html = document.documentElement, esc = L.escapeHtml, SIG = L.SIGLA;
  const tropeBefore = html.dataset.trope;
  if (new URLSearchParams(location.search).get("trope") !== "1") delete html.dataset.trope;   // pastels blur in a video stream
  html.dataset.present = "1";
  const host = document.createElement("section");
  host.className = "present"; host.id = "present"; host.setAttribute("aria-label", "Presenter view");
  host.innerHTML = `
    <div class="p-top"><span class="p-label" id="pLabel" aria-live="polite"></span><span class="p-count" id="pCount"></span></div>
    <div class="p-body" id="pBody">
      <div class="p-he he" id="pHe" lang="he" dir="rtl"></div>
      <div class="p-en" id="pEn"></div>
      <div class="p-notes" id="pNotes" hidden></div>
    </div>
    <p class="p-next" id="pNext" hidden></p>
    <div class="p-nav">
      <span class="p-help" id="pHelp" hidden>→ or PageDown next · ← or PageUp back · B blank · C commentary · N next verse · T trope colors · + − size · Esc exit</span>
      <button type="button" id="pPrev">Previous</button><button type="button" id="pFwd">Next</button><button type="button" id="pExit">Exit</button>
    </div>
    <div class="p-blank" id="pBlank" hidden></div>`;
  document.body.append(host);
  const $ = id => host.querySelector(`#${id}`);
  let i = startIndex(rows.map(r => ({ reading: r.row.dataset.reading, chapter: r.v.chapter, verse: r.v.verse })), location.hash);
  let user = 1, lock = null;

  // A long verse shrinks (to half size at most) rather than scroll.
  function fit() {
    const body = $("pBody");
    let s = 1;
    body.style.setProperty("--p-fit", "1");
    while (s > 0.5 && body.scrollHeight > body.clientHeight + 1) { s = Math.round((s - 0.05) * 100) / 100; body.style.setProperty("--p-fit", String(s)); }
  }
  function show() {
    const r = rows[i], v = r.v, next = rows[i + 1];
    $("pLabel").textContent = L.enDash(v.ref);
    $("pCount").textContent = `${i + 1} / ${rows.length}`;
    $("pHe").innerHTML = stripKeys(v.heHtml);
    $("pEn").innerHTML = v.enLines.map(t => `<span class="ln">${stripKeys(t)}</span>`).join("");
    $("pNotes").innerHTML = v.entries.length
      ? v.entries.map(e => `<p class="p-entry reg-${e.register}"><span class="sig">${SIG[e.register]}</span><b>${esc(e.source)}</b> ${e.bodyHtml}</p>`).join("")
      : `<p class="p-entry">No commentary on this verse.</p>`;
    $("pNext").textContent = next ? `Next: ${L.plainText(next.v.enLines[0] || "").text.trim()}` : "";
    history.replaceState(null, "", `${location.pathname}${location.search}#${r.row.id}`);
    fit();
  }
  function act(a) {
    const blank = $("pBlank");
    if (!blank.hidden && a !== "exit") { blank.hidden = true; return; }   // any key brings the verse back
    switch (a) {
      case "next": case "prev": case "first": case "last": { const j = stepIndex(i, rows.length, a); if (j !== i) { i = j; show(); } return; }
      case "blank": blank.hidden = false; return;
      case "notes": $("pNotes").hidden = !$("pNotes").hidden; fit(); return;
      case "preview": $("pNext").hidden = !$("pNext").hidden; fit(); return;
      case "trope": if (html.dataset.trope) delete html.dataset.trope; else html.dataset.trope = "1"; return;
      case "bigger": case "smaller":
        user = Math.min(2, Math.max(0.6, Math.round(user * (a === "bigger" ? 1.1 : 1 / 1.1) * 100) / 100));
        host.style.setProperty("--p-user", String(user)); fit(); return;
      case "help": $("pHelp").hidden = !$("pHelp").hidden; return;
      case "exit": exit(); return;
    }
  }
  function onKey(e) {
    const a = presentAction({ key: e.key, ctrlKey: e.ctrlKey, metaKey: e.metaKey, altKey: e.altKey, onControl: !!(e.target && e.target.closest && e.target.closest("button, a")) });
    if (!a) return;
    e.preventDefault(); e.stopPropagation();
    act(a);
  }
  // The screen stays awake while presenting, where the browser allows it.
  const wake = async () => { try { if (navigator.wakeLock && document.visibilityState === "visible") lock = await navigator.wakeLock.request("screen"); } catch {} };
  function exit() {
    document.removeEventListener("keydown", onKey, true);
    document.removeEventListener("visibilitychange", wake);
    removeEventListener("resize", fit);
    if (lock) lock.release().catch(() => {});
    const r = rows[i];
    host.remove();
    delete html.dataset.present;
    if (tropeBefore) html.dataset.trope = tropeBefore; else delete html.dataset.trope;
    const q = new URLSearchParams(location.search); q.delete("present");
    history.replaceState(null, "", `${location.pathname}${q.toString() ? `?${q}` : ""}#${r.row.id}`);
    r.row.scrollIntoView({ block: "start" });
    onExit(r);
  }
  document.addEventListener("keydown", onKey, true);
  document.addEventListener("visibilitychange", wake);
  addEventListener("resize", fit);
  $("pPrev").addEventListener("click", () => act("prev"));
  $("pFwd").addEventListener("click", () => act("next"));
  $("pExit").addEventListener("click", () => act("exit"));
  $("pBlank").addEventListener("click", () => { $("pBlank").hidden = true; });
  wake();
  track("present_start", {});
  show();
  $("pFwd").focus({ preventScroll: true });
  return { act, exit, index: () => i, host };
}
```

```markdown
### Presenter view
`?present` covers the page with one verse at a time for a shared screen, in a fixed light palette whatever the theme (paper #ffffff, ink #000000, rubric #8a0a14, the light register colors). The verse label in rubric and "3 / 22" in ink-2 sit at the top at 1.6vh + .6rem. Hebrew in Ezra SIL at clamp(1.6rem, 7vh, 5.5rem) with 1.6 leading; English at clamp(1.2rem, 4.2vh, 3.2rem) with 1.4; the verse's commentary under a 1px rule at clamp(1rem, 2.6vh, 2rem). A long verse shrinks all three together, to half size at most, rather than scroll; − and + scale them by a tenth between .6 and 2. Previous, Next and Exit are 44px outlined buttons at the bottom right. B is a black screen. Trope colors start off. Nothing moves.

### Verse links and highlights
A verse reached by its link takes the active-word wash. A teacher highlight is a 3px rubric bar inside the verse's left edge, a tint on its words (rgba(138,10,20,.10); dark rgba(224,97,107,.18)) and its note in the apparatus behind a 2px rubric rule. The verse header's "Copy link" and "Copy verse" are set like "on Sefaria": ink-2 italic at .85em, rubric on hover.

### Show
Hebrew, Both or English. One language alone turns the wide row into two tracks, the verse number (2.8rem) then the text; English alone keeps a 42em measure.

### No inline styles
The Content-Security-Policy forbids style attributes, so every style lives in web.css; a script that positions something (the note popover, the presenter's fit) uses the CSSOM, which the policy allows.
```
