# Haftarah 2.0, Wave 5: the offline app — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make haftarah.centralreform.org an installable app that opens the sheets a reader has already seen with no network, picks a new build up only on its next launch, tells iPad and iPhone Safari readers how to add it to the Home Screen, and lets a reader keep their own marks on a sheet, on their device, with a link and a text to share them.

**Architecture:** A hand-written service worker, `site/sw.js`, is a thin module worker over pure functions in `site/app/offline.js` (what to precache, which cache answers which request, how a navigation falls back to a cached shell, how the week files and Sefaria answers are kept and bounded); `scripts/web-build.mjs` writes the build hash and the precache list into the worker it copies, so a cache name changes exactly when a shipped file does. `site/app/offline-client.js` registers the worker from every page and shows an "updated" note when a new build is waiting; it never reloads. `site/manifest.webmanifest` and four PNG icons rendered from the mural by a one-time tool make the site installable; `site/app/install.js` shows a two-step card only in iPad and iPhone Safari outside the installed app. `site/app/marks.js` holds a reader's own marks under the `haftarah:v1:` prefix, with the list, the link (`#m=…`, a fragment that never reaches a server) and the text in the week page's panel. Nothing in `template/` changes, so the print golden holds without a re-record.

**Tech Stack:** Node 18+ (the machine runs 24), zero npm dependencies, `node --test`, headless Chrome/Edge through `scripts/chrome.mjs` (a `screenshot` helper is added beside `dumpDom`), Service Worker and Cache APIs, a Web App Manifest; no Workbox, no framework.

**Spec:** `docs/superpowers/specs/2026-10-15-web-2-0-design.md` (sections 5.1 "Content-Security-Policy" and "Storage", 5.2 "Device-local highlights", 5.10, 9 row 5, 10, 11 item 5). Background: `docs/superpowers/research/2026-10-15-web-2-0/reader-features.md` sections 3 and 4. Daniel's rulings (binding, memory `web-2-0-decisions`, `trope-engine-branch`): Wave 5 is the offline app alone; no audio of any kind; device-local highlights with an export link and no accounts; an iPad install card. Format and earlier decisions: `docs/superpowers/plans/2026-10-15-web-2-0-wave-4.md`.

**Verified before planning (2026-10-15, controller):** headless Chrome 155 on this machine writes a PNG of exactly the `--window-size` (512×512, 338 KB) with `--screenshot=<path>` from a `file://` page that loads `assets/logo.png` (a `data:` page cannot load the file; the mural is a circle with a red ring on a white ground, 1335 px square, 2.36 MB). The files the site ships: the four fonts the stylesheets use total 2.15 MB (Literata 936 KB, Literata Italic 884 KB, Noto Serif Hebrew 180 KB, Ezra SIL 152 KB; `EzraSIL-SR.ttf` is copied but used by neither stylesheet), `mural.png` 2.36 MB, `basemap.json` 84 KB, `lib.js` 56 KB, `web.css` 40 KB: a full precache is about 5 MB. `site/app/parashot.js` has no imports and touches no DOM, so a module service worker can import `isAliasPath` from it and `slugFromPath` from `contract.js`. Node 24's global `Request` refuses `mode: "navigate"`, so the worker logic takes a plain `{ url, method, mode }` record, not a `Request`. `storage.js`'s `store()` swallows a throwing storage and returns nothing; marks need to know (Task 4 makes it return a boolean). The page sets `document.documentElement.dataset.present = "1"` while the presenter is open (`present.js:51`), which is how the update note stays off a shared screen. `vercel.json`'s header rule `/((?!data/).*)` already covers `/sw.js` and `/manifest.webmanifest`; Vercel serves static files with `public, max-age=0, must-revalidate`, so the worker script is revalidated on every check, and registration uses `updateViaCache: "none"` so its imports are too. Module service workers are supported by Chrome 91, Safari 15 and Firefox 114; `web-check` serves `.js` as `text/javascript` and pages under the real policy from `127.0.0.1`, a secure context, so the worker registers in the check. `analytics.js` already carries the `install` event and both pages already send it on `appinstalled`.

## Global Constraints

- Node 18+, no npm dependencies, no `npm install`; the site is plain HTML/CSS/ES modules, no framework; the worker is hand-written, no Workbox.
- **Nothing in `template/` changes.** `template/lib.js`, `render.js`, `sheet.css`, `sheet.html` and the fonts are untouched; `tests/golden/print.json` is not re-recorded; `node scripts/golden.mjs --update`, `--update-dom`, `--update-sources` and `--add` are never run. A diff that touches `template/` is a plan violation.
- **Content-Security-Policy** (`vercel.json`, `tests/csp.test.mjs`, exact): `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self'; font-src 'self'; connect-src 'self' https://www.sefaria.org; worker-src 'self'; manifest-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'`. No inline `<script>`, no `style` attribute, no inline event handler anywhere in `site/` (the existing tests hold this); the worker and the manifest are same-origin files.
- **Storage:** every per-device value lives under the `haftarah:v1:` prefix through `site/app/storage.js` (`marks:<slug>`, `install-card`); every access is guarded; the page works the same with storage blocked. Marks are never sent anywhere: the share link carries them in the URL fragment only, and the worker never logs or forwards a URL.
- **Caches** (names in `site/app/contract.js`): `haftarah-shell-<build>` (the precached shell, replaced whole on a new build), `haftarah-data` (week files and the index, at most `DATA_LIMIT = 60` entries), `haftarah-sefaria` (answers from `https://www.sefaria.org`, at most `SEFARIA_LIMIT = 100` entries). PDFs under `/data/` and any non-GET request are never cached. The worker never calls `skipWaiting()`: a new build waits for the next launch.
- **The build hash** is `sha256` over the output files' paths and bytes, the first 12 hex characters, written into `sw.js` by `web-build` (`const BUILD = "<hash>"`) together with the precache list (`const PRECACHE = [...]`); two builds of the same tree give the same hash; one changed byte in any shipped file changes it.
- **Network:** no test reaches the network beyond `127.0.0.1`; the worker's logic is tested with a fake `caches` and an injected `fetchImpl` in Node; the real worker is exercised by `web-check` against its own server.
- **Test isolation:** any test file that starts another program imports `./helpers/isolatedEnv.mjs`, calls `isolatedEnv()`, passes its `env`, and never reads `process.env`. `tools/make-icons.mjs` is a tool, not a test, and may use the machine's Chrome.
- Tokens are never printed, logged or put in error messages.
- **Customs are data.** Nothing CRC-specific enters `site/app/offline.js`, `marks.js` or `install.js`. The manifest's name and the card's wording are product strings, listed below for Daniel.
- **No audio of any kind** (Daniel, 2026-10-15): no `media-src`, no `/audio/`, nothing from the trope branch.
- **Accessibility floor (Wave 1's):** every new control is a 44px target with a keyboard path; the update note and the shared-marks strip are `role="status"`; the marks list is a list; a marked verse is named to a screen reader (the verse number's name ends " Marked.", as a teacher highlight's ends " Highlighted."); colour is never the only signal (a reader's mark is a bar on the row's right edge and an underline under the verse number; the teacher's is a bar on the left).
- **Design tokens** are DESIGN.md's: a reader's mark takes the reference ochre (`--reg-reference`, print `#8a5a00`, dark `#d7b05c`); the shared-marks outline takes `--ink-2`; the update note and the install card sit on `--paper` inside a `.5px` `--rule` frame, like the settings card, with no shadow.
- **User-visible strings** (drafts for Daniel to see after the deploy, Wave 2's precedent; exact values in the tasks): the manifest name "Haftarah · Torah from Scratch" and short name "Haftarah"; the update note "This site has been updated. The new version opens the next time you launch it." with "Dismiss"; the offline load message "You're offline, and this sheet isn't saved on this device yet."; the install card "Keep these sheets on this iPad" / "on this iPhone", its two steps "Tap Share (the square with an arrow)." and "Tap Add to Home Screen.", its note "Sheets you have opened stay readable without a connection, and your marks are kept." and "Not now"; the marks strings "Mark this verse", "Unmark", "My marks", "No marks yet. Press and hold a verse number, or use Mark this verse in its header. Marks stay on this device.", "Copy link to my marks", "Copy my marks as text", "Remove", "N marked verses shared with you." / "1 marked verse shared with you.", "Add to my marks", "This mark could not be saved on this device."
- Every commit message ends with the attribution trailer the executing session is given.

## Review Focus

Inputs the spec implies that a person will meet and no task's tests would otherwise exercise; each line's test is added to the owning task.

1. **A reader on the page while a new build deploys** (every Friday): the new worker installs and waits; the page is never reloaded; the note appears only when there is a controlling worker (a first install shows nothing). → Task 1 test "precacheAll never skips waiting; dropOldCaches keeps the current shell"; Task 3 test "onUpdate fires for a waiting worker with a controller, not on a first install".
2. **A republished week** (same slug, corrected text): the open page keeps what it has; the next launch shows the new text. → Task 1 test "a week file is answered from the cache and refreshed behind it; the next request gets the new body".
3. **Offline, a week never opened on this device:** the page says it is offline, not "try Drive"; the worker answers with an error, not a hang. → Task 1 test "an uncached week offline is an error response"; Task 3 test "the load message says offline when the browser is offline".
4. **Private browsing or blocked storage:** marking a verse says it could not be saved; nothing throws; the page still shows the mark for this view. → Task 4 test "a throwing storage reports unsaved and keeps the mark on the page".
5. **A shared marks link that names verses not on this page, or is malformed** (`#m=`, `#m=99-99`, `#m=haftarah-54-3,junk`): only the verses on the page count; an empty result shows no strip and changes nothing; the teacher's highlights are untouched. → Task 4 tests "parseMarks drops what it cannot read" and the web-check line "a shared link to no verse shows no strip".
6. **Sefaria answers pile up over a year:** the 101st answer evicts the oldest; the cache never grows past the bound. → Task 1 test "putTrimmed keeps the newest N".
7. **The installed app, and a desktop browser:** the install card never shows in standalone mode, on Chrome or Edge, or in iOS Chrome; it shows once in iPad and iPhone Safari and stays dismissed. → Task 5 tests and web-check lines with an iPhone Safari user agent and the default one.

```js
import assert from "node:assert/strict";
import { classify, shellFor, precacheAll, dropOldCaches, putTrimmed, withTimeout, handle, DATA_LIMIT, SEFARIA_LIMIT } from "../site/app/offline.js";
import { shellCache, DATA_CACHE, SEFARIA_CACHE, SEFARIA_ORIGIN } from "../site/app/contract.js";

const ORIGIN = "https://haftarah.centralreform.org";
class FakeCache {
  constructor() { this.map = new Map(); }
  async match(url) { const r = this.map.get(typeof url === "string" ? url : url.url); return r ? r.clone() : undefined; }
  async put(url, res) { const k = typeof url === "string" ? url : url.url; this.map.delete(k); this.map.set(k, res); }
  async keys() { return [...this.map.keys()].map(u => ({ url: u })); }
  async delete(url) { return this.map.delete(typeof url === "string" ? url : url.url); }
  async addAll(urls) { for (const u of urls) this.map.set(new URL(u, ORIGIN).href, new Response(`body of ${u}`)); }
}
class FakeCaches {
  constructor() { this.stores = new Map(); }
  async open(name) { if (!this.stores.has(name)) this.stores.set(name, new FakeCache()); return this.stores.get(name); }
  async keys() { return [...this.stores.keys()]; }
  async delete(name) { return this.stores.delete(name); }
  async has(name) { return this.stores.has(name); }
}
const PRE = ["/", "/sheet.html", "/library.html", "/404.html", "/web.css", "/lib.js", "/app/sheet.js", "/fonts/EzraSIL.ttf"];
const env = (caches, fetchImpl, extra = {}) => ({ caches, fetchImpl, build: "abc123def456", precache: new Set(PRE), origin: ORIGIN, timeoutMs: 50, ...extra });
const get = (path, mode = "cors") => ({ url: new URL(path, ORIGIN).href, method: "GET", mode });
const ok = (body, status = 200) => new Response(body, { status, headers: { "content-type": "application/json" } });
const offline = () => Promise.reject(new TypeError("Failed to fetch"));

test("classify: the shell by the precache list, week files, the index, PDFs, Sefaria, anything else", () => {

test("precacheAll fills the build's shell cache and never skips waiting; dropOldCaches keeps the current shell and the data caches", async () => {

test("handle: a week file is answered from the cache and refreshed behind it; the next request gets the new body", async () => {
  const caches = new FakeCaches();
  let body = "v1";
  const e = env(caches, () => Promise.resolve(ok(body)));
  const pending = [];
  const wait = p => pending.push(p);
  const url = "/data/weeks/2026-10-17-noach/sheet.json";
  assert.equal(await (await handle(get(url), e, wait)).text(), "v1", "a miss goes to the network");
  await Promise.all(pending);
  body = "v2";
  assert.equal(await (await handle(get(url), e, wait)).text(), "v1", "a hit is the cached body, served at once");
  await Promise.all(pending);
  assert.equal(await (await handle(get(url), e, wait)).text(), "v2", "the refresh landed for the next launch");
  const down = env(caches, offline);
  assert.equal(await (await handle(get(url), down, wait)).text(), "v2", "offline, the cache answers");
```

```js
// The offline app's logic (spec 5.10), pure: what the worker precaches, which cache answers which
// request, how a navigation falls back to a cached shell when the network is away, and how the week
// files and Sefaria's answers are kept and bounded. sw.js is three listeners over these; the tests
// drive them with a fake cache storage. Requests arrive as plain records ({ url, method, mode }): a
// Request cannot be built with mode "navigate" outside a browser.
import { slugFromPath, shellCache, CACHE_PREFIX, DATA_CACHE, SEFARIA_CACHE, SEFARIA_ORIGIN } from "./contract.js";
import { isAliasPath } from "./parashot.js";

export const DATA_LIMIT = 60;          // week files and the index: about a year of weeks with their side files
export const SEFARIA_LIMIT = 100;      // answers kept from Sefaria
export const NETWORK_TIMEOUT_MS = 3000;

/** Which cache, if any, a request belongs to. `precache` is the set of shell paths web-build wrote. */
export function classify(url, { origin, precache }) {
  const u = url instanceof URL ? url : new URL(url);
  if (u.origin === SEFARIA_ORIGIN) return "sefaria";
  if (u.origin !== origin) return "other";
  const p = u.pathname;
  if (p === "/data/index.json") return "index";
  if (/^\/data\/weeks\/[^/]+\/[^/]+\.json$/.test(p)) return "week";
  if (p.startsWith("/data/")) return "pdf";
  if (precache.has(p) || (p === "/index.html" && precache.has("/"))) return "shell";
  return "other";
}

/** The precached page that serves a navigation to `pathname` when the network cannot. */
export function shellFor(pathname) {
  const p = String(pathname || "/");
  if (p === "/" || p.toLowerCase() === "/index.html") return "/";
  if (slugFromPath(p)) return "/sheet.html";
  if (isAliasPath(p.toLowerCase())) return "/library.html";
  return "/404.html";
}

/** install: fill this build's shell cache. The worker then waits for the next launch: no skipWaiting. */
export async function precacheAll({ caches, build, precache }) {
  const cache = await caches.open(shellCache(build));
  await cache.addAll([...precache]);
}

/** activate: drop every other build's shell; the data and Sefaria caches are shared across builds and kept. */
export async function dropOldCaches({ caches, build }) {
  const keep = shellCache(build);
  for (const name of await caches.keys()) {
    if (name.startsWith(`${CACHE_PREFIX}shell-`) && name !== keep) await caches.delete(name);
  }
}

/** Put a response and drop the oldest entries past `limit` (the Cache API lists keys in insertion order). */
export async function putTrimmed(cache, url, response, limit) {
  await cache.delete(url);   // re-putting moves it to the end
  await cache.put(url, response);
  const keys = await cache.keys();
  for (const k of keys.slice(0, Math.max(0, keys.length - limit))) await cache.delete(k);
}

export function withTimeout(promise, ms) {
  let timer;
  const clock = new Promise((_, reject) => { timer = setTimeout(() => reject(new Error(`timed out after ${ms}ms`)), ms); });
  return Promise.race([promise, clock]).finally(() => clearTimeout(timer));
}

const good = r => r && r.ok;

/**
 * The fetch handler: null when the browser should handle the request itself, else a promise of the
 * response. `waitUntil` receives the background work (a refresh, a put) so the worker stays alive for it.
 */
export function handle(req, env, waitUntil) {
  if (req.method !== "GET") return null;
  const url = new URL(req.url);
  const timeoutMs = env.timeoutMs ?? NETWORK_TIMEOUT_MS;
  const fetchImpl = env.fetchImpl;
  if (req.mode === "navigate") return navigate(url, req, env, timeoutMs);
  const kind = classify(url, env);
  if (kind === "shell") return cacheFirst(shellCache(env.build), req, env, waitUntil);
  if (kind === "week") return staleWhileRevalidate(req, env, waitUntil);
  if (kind === "index") return networkFirst(DATA_CACHE, req, env, timeoutMs, waitUntil, DATA_LIMIT);
  if (kind === "sefaria") return networkFirst(SEFARIA_CACHE, req, env, timeoutMs, waitUntil, SEFARIA_LIMIT);
  return null;

  async function navigate(u, r, e, ms) {
    try { const live = await withTimeout(fetchImpl(r), ms); if (good(live)) return live; } catch {}
    const shell = await (await e.caches.open(shellCache(e.build))).match(new URL(shellFor(u.pathname), e.origin).href);
    return shell || Response.error();
  }
}

async function cacheFirst(name, req, env, waitUntil) {
  const cache = await env.caches.open(name);
  const hit = await cache.match(req.url);
  if (hit) return hit;
  const live = await env.fetchImpl(req);
  if (good(live)) waitUntil(cache.put(req.url, live.clone()));
  return live;
}

async function staleWhileRevalidate(req, env, waitUntil) {
  const cache = await env.caches.open(DATA_CACHE);
  const hit = await cache.match(req.url);
  const refresh = () => env.fetchImpl(req).then(live => { if (good(live)) return putTrimmed(cache, req.url, live.clone(), DATA_LIMIT).then(() => live); return live; });
  if (hit) { waitUntil(refresh().catch(() => {})); return hit; }
  try { return await refresh(); } catch { return Response.error(); }
}

async function networkFirst(name, req, env, ms, waitUntil, limit) {
  const cache = await env.caches.open(name);
  try {
    const live = await withTimeout(env.fetchImpl(req), ms);
    if (good(live)) { waitUntil(putTrimmed(cache, req.url, live.clone(), limit)); return live; }
  } catch {}
  return (await cache.match(req.url)) || Response.error();
}
```

Note on `putTrimmed`'s delete-then-put: the fake and the real Cache API both list keys in insertion order, so re-putting an existing key must move it to the end for the bound to be an LRU. The test "a 500 never replaces a good body" needs the refresh to skip the put when the response is not `ok`.

```js
/** The shell paths the worker holds: every output file but the worker itself and the licence texts; index.html is "/". */
export function precacheList(files) {
  return files.filter(f => f !== "sw.js" && !f.endsWith(".txt")).map(f => f === "index.html" ? "/" : `/${f}`).sort();
}

/** sha256 over [path, bytes] pairs in path order, the first 12 hex characters. */
export function buildHash(entries) {
  const h = createHash("sha256");
  for (const [path, bytes] of [...entries].sort((a, b) => a[0] < b[0] ? -1 : 1)) { h.update(path); h.update("\0"); h.update(bytes); h.update("\0"); }
  return h.digest("hex").slice(0, 12);
}

/** The worker with its build hash and precache list written in. */
export function fillWorker(source, build, precache) {
  const a = source.replace(/const BUILD = "[^"]*";/, () => `const BUILD = "${build}";`);
  const b = a.replace(/const PRECACHE = \/\*precache\*\/\[\];/, () => `const PRECACHE = ${JSON.stringify(precache)};`);
  if (a === source || b === a) throw new Error("sw.js: the BUILD or PRECACHE line to fill was not found");
  return b;
}
```

```js
// waiting (it is used on the next launch; the page is never reloaded), and warm this week's sheet
// into the cache from the landing. Nothing here runs in the presenter: the note is hidden by CSS

export async function registerOffline({ nav = navigator, onUpdate = () => {} } = {}) {
  if (!nav || !nav.serviceWorker) return null;
  let reg;
  try { reg = await nav.serviceWorker.register(SW_URL, { type: "module", updateViaCache: "none" }); } catch { return null; }
```

```js
/** A reader's marks in a share link: "#m=haftarah-54-3,haftarah-54-9". A bare "54-9" means the primary reading. */
export const formatMarks = anchors => `m=${anchors.join(",")}`;
export function parseMarks(hash, primaryReading) {
  const h = String(hash == null ? "" : hash).replace(/^#/, "");
  if (!h.startsWith("m=")) return null;
  const out = [];
  for (const item of h.slice(2).split(",")) {
    const a = parseVerseAnchor(item.startsWith("v") ? item : /^\d/.test(item) ? `v${item}` : item);
    if (!a) continue;
    const anchor = verseAnchor(a.reading == null ? primaryReading : a.reading, a.chapter, a.verse);
    if (!out.includes(anchor)) out.push(anchor);
  }
  return out;
}
```
